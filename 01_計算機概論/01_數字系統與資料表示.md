## 觀念 1：進位制與轉換

### 1.1 四種常見進位
| 進位 | 基底 | 使用符號 | 寫法範例 |
|---|---|---|---|
| 二進位 | 2 | 0、1 | (1011)₂ |
| 八進位 | 8 | 0–7 | (13)₈ |
| 十進位 | 10 | 0–9 | (11)₁₀ |
| 十六進位 | 16 | 0–9、A–F | (B)₁₆ 或 0xB |

### 1.2 任意進位 → 十進位：位值展開
$(3A.8)_{16} = 3×16^1 + 10×16^0 + 8×16^{-1} = 48 + 10 + 0.5 = 58.5$

### 1.3 十進位 → 二進位
- **整數部分**：連除 2，取餘數，**由下往上**讀。
- **小數部分**：連乘 2，取整數位，**由上往下**讀。

```
156 ÷ 2 = 78 … 0
 78 ÷ 2 = 39 … 0
 39 ÷ 2 = 19 … 1
 19 ÷ 2 =  9 … 1
  9 ÷ 2 =  4 … 1
  4 ÷ 2 =  2 … 0
  2 ÷ 2 =  1 … 0
  1 ÷ 2 =  0 … 1   → 由下往上：10011100
```
小技巧：記住 2 的次方 `128 64 32 16 8 4 2 1`，156 = 128+16+8+4 → `1001 1100`，比連除快很多。

### 1.4 二進位 ↔ 八 / 十六進位：分組法
- 八進位：每 **3** 位一組（從小數點往兩側分）。
- 十六進位：每 **4** 位一組。

`10110111₂` → `010 110 111` → `267₈`　；　→ `1011 0111` → `B7₁₆`

> ⚠️ 有些十進位小數（例如 0.1）轉成二進位是**無限循環**，因此電腦無法精確表示 0.1，這是浮點誤差的根源。

## 觀念 2：有號整數的表示法

| 表示法 | 正數 | 負數做法 | n 位元範圍 | 0 的表示 |
|---|---|---|---|---|
| 符號-大小 (Sign-Magnitude) | 最高位 0 | 最高位改 1 | −(2ⁿ⁻¹−1) ~ 2ⁿ⁻¹−1 | 兩個（+0、−0） |
| 1 的補數 | 原樣 | 全部位元反轉 | −(2ⁿ⁻¹−1) ~ 2ⁿ⁻¹−1 | 兩個 |
| **2 的補數** | 原樣 | **反轉後 +1** | **−2ⁿ⁻¹ ~ 2ⁿ⁻¹−1** | **一個** |

> 現代電腦幾乎都用 **2 的補數**：只有一個 0，而且加減法可共用同一個加法器。
> 8 位元 2 的補數範圍：**−128 ~ 127**。

**範例：−45 的 8 位元 2 的補數**
```
 45 = 0010 1101
反轉 = 1101 0010
 +1  = 1101 0011   ← −45
```

**快速解讀負數**：最高位是 1 → 再取一次 2 的補數得到絕對值。
`1111 0110` → 反轉 `0000 1001` +1 → `0000 1010` = 10 → 所以是 **−10**。

**另一個快速法**：最高位權重當成負的。`1111 0110` = −128 + 64+32+16+4+2 = −128+118 = −10。

## 觀念 3：溢位（Overflow）與位移

### 3.1 溢位判斷規則（2 的補數加法）
- **正 + 正 = 負** → 溢位
- **負 + 負 = 正** → 溢位
- 一正一負相加 → **永遠不會**溢位
- 硬體判斷法：**最高位的進位輸入 ≠ 最高位的進位輸出** → 溢位（Cin ⊕ Cout = 1）

範例（8 位元）：100 + 50
```
  0110 0100  (100)
+ 0011 0010  ( 50)
-----------
  1001 0110  → 最高位是 1，變成 −106 → 溢位！
```

> 注意 **進位（carry）≠ 溢位（overflow）**：進位是無號數的概念，溢位是有號數的概念。

### 3.2 位移運算
- **邏輯左移 1 位** ≈ ×2；**右移 1 位** ≈ ÷2（取整）
- **算術右移**：補符號位（保持正負號），用於有號數；**邏輯右移**：補 0。

## 觀念 4：浮點數 IEEE 754

### 4.1 單精度（32 位元）格式
| 符號 S | 指數 E | 尾數 M（fraction） |
|---|---|---|
| 1 位 | 8 位（**偏差值 bias = 127**） | 23 位 |

數值 = $(-1)^S × 1.M × 2^{E-127}$（正規化數，小數點前隱含的 1 不儲存）

雙精度（64 位元）：1 + **11**（bias **1023**）+ **52**。

### 4.2 範例：−6.75 轉單精度
1. 6.75 = 110.11₂
2. 正規化：1.1011 × 2²
3. S = 1；E = 2 + 127 = 129 = 1000 0001；M = 1011 000…0
4. 組合：`1 10000001 10110000000000000000000`
5. 每 4 位一組：`1100 0000 1101 1000 0000 …` = **0xC0D80000**

### 4.3 特殊值
| E | M | 意義 |
|---|---|---|
| 全 0 | 全 0 | ±0 |
| 全 0 | 非 0 | 非正規化數（極小數） |
| 全 1 | 全 0 | ±∞ |
| 全 1 | 非 0 | NaN |

## 觀念 5：字元與其他編碼

| 編碼 | 重點 |
|---|---|
| **ASCII** | 7 位元，128 字元。`'0'`=48（0x30）、`'A'`=65（0x41）、`'a'`=97（0x61），大小寫差 **32** |
| **Big5** | 繁體中文，每個中文字 2 bytes |
| **Unicode** | 統一字碼，為全世界字元編號（code point，如 U+4E2D） |
| **UTF-8** | Unicode 的可變長度實作：英數 1 byte，**常用中文 3 bytes**，最多 4 bytes；相容 ASCII |
| **UTF-16** | 2 或 4 bytes |
| **BCD** | 每個十進位數字用 4 位元表示：59 → `0101 1001` |
| **Excess-3** | BCD + 3 |
| **格雷碼 Gray Code** | 相鄰兩數只差 1 位元；`G = B ⊕ (B >> 1)` |

## 觀念 6：資料單位、容量計算與錯誤偵測

### 6.1 單位
- 1 Byte = 8 bits；1 KB = 2¹⁰ B；1 MB = 2²⁰ B；1 GB = 2³⁰ B
- **n 條位址線可定址 2ⁿ 個位置**：32 位元位址 → 2³² B = 4 GB
- 網路速率用十進位：1 Mbps = 10⁶ bits/s（注意是小寫 **b**＝bit）

### 6.2 檔案大小計算
未壓縮影像 = 寬 × 高 × 每像素位元數 ÷ 8（bytes）

### 6.3 錯誤偵測與更正
- **同位元檢查（Parity）**：只能偵測**奇數個**位元錯誤，不能更正。
- **漢明碼（Hamming Code）**：可**更正 1 位元錯誤**。資料 m 位元需要 r 個檢查位元，滿足 **2ʳ ≥ m + r + 1**。
- **CRC**：網路常用的偵錯方法（乙太網路訊框尾端的 FCS）。

## 📝 本章重點速記

- 2 的次方表：`1 2 4 8 16 32 64 128 256 512 1024`
- 二轉八：3 位一組；二轉十六：4 位一組
- n 位元 2 的補數範圍：**−2ⁿ⁻¹ ~ 2ⁿ⁻¹−1**；1 的補數與符號-大小：**±(2ⁿ⁻¹−1)**，有兩個 0
- 溢位：同號相加變異號；Cin ⊕ Cout
- IEEE 754 單精度：1 / 8（bias 127）/ 23；雙精度：1 / 11（bias 1023）/ 52
- ASCII：`'0'`=48、`'A'`=65、`'a'`=97；UTF-8 中文 3 bytes
- 格雷碼：G = B ⊕ (B>>1)；漢明碼：2ʳ ≥ m + r + 1
