> 學習目標：熟記邏輯閘真值表、會用布林定律與卡諾圖化簡、認識加法器／多工器／正反器等基本元件。

## 觀念 1：基本邏輯閘

| 閘 | 符號式 | 輸出為 1 的條件 | A=0,B=0 | 0,1 | 1,0 | 1,1 |
|---|---|---|---|---|---|---|
| AND | A·B | 全部為 1 | 0 | 0 | 0 | 1 |
| OR | A+B | 至少一個 1 | 0 | 1 | 1 | 1 |
| NAND | (A·B)' | 不全為 1 | 1 | 1 | 1 | 0 |
| NOR | (A+B)' | 全部為 0 | 1 | 0 | 0 | 0 |
| XOR | A⊕B | **兩者不同** | 0 | 1 | 1 | 0 |
| XNOR | (A⊕B)' | **兩者相同** | 1 | 0 | 0 | 1 |
| NOT | A' | 輸入為 0 | — | — | — | — |

- **萬用閘（Universal Gate）**：**NAND、NOR**。只用其中一種就能組出所有邏輯函數。
- XOR 的用途：比較器、同位元產生器、加法器的「和」。
- A ⊕ A = 0；A ⊕ 0 = A；A ⊕ 1 = A'。

## 觀念 2：布林代數定律與化簡

| 定律 | 加法形式 | 乘法形式 |
|---|---|---|
| 單位律 | A + 0 = A | A · 1 = A |
| 支配律 | A + 1 = 1 | A · 0 = 0 |
| 冪等律 | A + A = A | A · A = A |
| 互補律 | A + A' = 1 | A · A' = 0 |
| 吸收律 | **A + AB = A** | A(A + B) = A |
| 消去律 | **A + A'B = A + B** | A(A' + B) = AB |
| 分配律 | A + BC = (A+B)(A+C) | A(B+C) = AB + AC |
| **笛摩根定律** | **(A + B)' = A'B'** | **(AB)' = A' + B'** |

> 笛摩根口訣：**「斷線、變號」**——上面那條補數線斷開，+ 與 · 互換。

**化簡範例**：F = A'B'C + A'BC + AB'C + ABC
= A'C(B' + B) + AC(B' + B) = A'C + AC = C(A' + A) = **C**

## 觀念 3：標準式與卡諾圖（K-map）

### 3.1 最小項與最大項
- **最小項 mᵢ**：該列輸出為 1 的乘積項，用於 **SOP（積之和）**：F = Σm(…)
- **最大項 Mᵢ**：該列輸出為 0 的和項，用於 **POS（和之積）**：F = ΠM(…)
- 同一函數：Σm 的編號與 ΠM 的編號**互補**。

### 3.2 卡諾圖排列（格雷碼順序 00 01 11 10）

三變數（A 為列，BC 為行）：
```
        BC=00  01   11   10
A=0  |  m0   m1   m3   m2
A=1  |  m4   m5   m7   m6
```

四變數（AB 為列，CD 為行）：
```
         CD=00  01   11   10
AB=00 |  m0   m1   m3   m2
AB=01 |  m4   m5   m7   m6
AB=11 |  m12  m13  m15  m14
AB=10 |  m8   m9   m11  m10
```

### 3.3 圈法規則
1. 只能圈 **1, 2, 4, 8, 16** 個（2 的次方），且必須是**矩形**。
2. 圈越大越好，數量越少越好。
3. **上下、左右邊界相連**，四個角落也可以圈成一組。
4. 圈內**保持不變**的變數留下，會變動的消去。

## 觀念 4：組合邏輯電路

**組合電路**：輸出只取決於「目前」的輸入，**沒有記憶**。

| 元件 | 重點 |
|---|---|
| **半加器 (HA)** | S = A ⊕ B；C = AB（無法處理進位輸入） |
| **全加器 (FA)** | S = A ⊕ B ⊕ Cᵢₙ；Cₒᵤₜ = AB + Cᵢₙ(A ⊕ B)；可由 **2 個半加器 + 1 個 OR** 組成 |
| 漣波進位加法器 | n 個全加器串接，進位逐級傳遞，**速度慢** |
| 前瞻進位加法器 (CLA) | 預先算出進位，速度快、電路較複雜 |
| **多工器 (MUX)** | 2ⁿ 個輸入選 1 個輸出，需 **n 條選擇線** |
| 解多工器 (DEMUX) | 1 個輸入分到 2ⁿ 個輸出之一 |
| **解碼器 (Decoder)** | n 個輸入 → 2ⁿ 個輸出（只有一個為 1） |
| 編碼器 (Encoder) | 2ⁿ 個輸入 → n 個輸出 |

## 觀念 5：循序邏輯電路

**循序電路**：輸出取決於「目前輸入」**加上「過去狀態」**，有記憶元件，通常受**時脈（clock）**控制。

### 5.1 正反器（Flip-Flop）
| 種類 | 行為 | 特性方程式 |
|---|---|---|
| **SR** | S=1 設定、R=1 重置；**S=R=1 為不允許狀態** | Q⁺ = S + R'Q |
| **D** | 輸出 = 輸入 D（延遲一個時脈） | Q⁺ = D |
| **JK** | 同 SR，但 **J=K=1 時反轉（toggle）** | Q⁺ = JQ' + K'Q |
| **T** | T=1 反轉、T=0 保持 | Q⁺ = T ⊕ Q |

### 5.2 計數器與暫存器
- n 個正反器可記錄 **2ⁿ** 種狀態。
- **模 N 計數器**至少需要 **⌈log₂N⌉** 個正反器（例：模 10 → 4 個）。
- 非同步（漣波）計數器：後級時脈取自前級輸出，簡單但有延遲累積。
- 同步計數器：所有正反器共用同一時脈。
- **移位暫存器**：每個時脈資料往左或右移一格；可做串列↔並列轉換。
- **SRAM** 由正反器（栓鎖）構成；**DRAM** 由電容構成、需要定期**刷新（refresh）**。

## 📝 本章重點速記

- XOR：相異為 1；XNOR：相同為 1；**萬用閘 NAND、NOR**
- 吸收 A + AB = A；消去 A + A'B = A + B；笛摩根「斷線變號」
- 卡諾圖用格雷碼順序，邊界相連，圈 2 的次方個
- 全加器：S = A⊕B⊕C；Cout = AB + C(A⊕B)
- 2ⁿ 對 1 MUX → n 條選擇線；n 對 2ⁿ 解碼器
- JK：J=K=1 反轉；SR：S=R=1 禁止；模 N 計數器需 ⌈log₂N⌉ 個 FF
