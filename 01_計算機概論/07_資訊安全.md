## 觀念 1：資訊安全三要素（CIA）

| 要素 | 意義 | 破壞它的攻擊 |
|---|---|---|
| **機密性 Confidentiality** | 只有授權者能看到資料 | 竊聽、側錄（Sniffing）、資料外洩 |
| **完整性 Integrity** | 資料不被未授權竄改 | 竄改、中間人修改 |
| **可用性 Availability** | 授權者需要時能使用 | **DoS / DDoS**、勒索軟體 |

延伸：
- **鑑別（Authentication）**：確認「你是誰」
- **授權（Authorization）**：確認「你能做什麼」
- **不可否認性（Non-repudiation）**：事後無法否認做過某行為（靠**數位簽章**）
- **AAA**：Authentication、Authorization、Accounting（記錄稽核）

## 觀念 2：對稱式加密

**加密與解密使用同一把金鑰**（祕密金鑰）。速度快，適合大量資料；問題是**金鑰如何安全傳遞（金鑰分配問題）**。

| 演算法 | 區塊大小 | 金鑰長度 | 備註 |
|---|---|---|---|
| **DES** | 64 位元 | **56 位元**（含同位元為 64） | 已不安全 |
| 3DES | 64 位元 | 112 / 168 位元 | 執行三次 DES，慢 |
| **AES** | **128 位元** | **128 / 192 / 256 位元** | 目前主流標準 |
| RC4 | 串流加密 | 可變 | 已不建議使用（WEP 使用它） |

- **區塊加密（Block cipher）**：DES、AES；**串流加密（Stream cipher）**：RC4、ChaCha20
- **n 人兩兩通訊，需要 n(n−1)/2 把金鑰**

**古典加密**
- **凱撒密碼**（替換法）：每個字母往後移 k 位，例：k=3，`A→D`
- 換位法：字母位置重新排列

## 觀念 3：非對稱式加密（公開金鑰）

每人有一對金鑰：**公鑰（公開）＋ 私鑰（自己保管）**，一把加密只有另一把能解密。

| 目的 | 用誰的哪把鑰匙 |
|---|---|
| **加密（保密）** | 用**收件者的公鑰**加密 → 收件者用自己私鑰解密 |
| **數位簽章（證明身分）** | 用**寄件者的私鑰**簽章 → 任何人用寄件者公鑰驗證 |

| 演算法 | 數學基礎 | 用途 |
|---|---|---|
| **RSA** | **大數質因數分解**困難 | 加密、簽章 |
| **ECC**（橢圓曲線） | 橢圓曲線離散對數 | **較短金鑰達到相同安全強度**，適合行動裝置 |
| **Diffie-Hellman** | 離散對數 | **金鑰交換**（不是用來加密資料） |
| DSA | 離散對數 | 只做簽章 |

- **n 人通訊只需 2n 把金鑰**（每人一對）
- 缺點：運算慢 → 實務上採**混合式加密**：用非對稱加密傳遞「對稱會議金鑰」，再用對稱加密傳資料（TLS 就是如此）

### RSA 小例子
1. 選質數 p = 3、q = 11 → n = 33，φ(n) = (p−1)(q−1) = 20
2. 選 e = 3（與 20 互質）→ 公鑰 (e, n) = (3, 33)
3. 找 d 使 e × d ≡ 1 (mod 20) → d = 7（3×7 = 21）→ 私鑰 (7, 33)
4. 加密 m = 4：c = 4³ mod 33 = 64 mod 33 = **31**
5. 解密：31⁷ mod 33 = 4 ✓

## 觀念 4：雜湊函數、數位簽章與憑證

### 4.1 雜湊函數（Hash）
任意長度輸入 → **固定長度**輸出（訊息摘要）。
特性：**單向（不可逆）**、**抗碰撞**（很難找到兩個輸入產生相同輸出）、輸入微小改變輸出大幅改變（雪崩效應）。

| 演算法 | 輸出長度 | 狀態 |
|---|---|---|
| MD5 | **128** 位元 | 已被破解（找得到碰撞） |
| SHA-1 | **160** 位元 | 已被破解 |
| **SHA-256**（SHA-2 家族） | **256** 位元 | 目前主流 |
| SHA-3 | 可變 | 新標準 |

用途：驗證**完整性**、儲存密碼（加上**鹽 Salt** 防彩虹表攻擊）。
**HMAC** = 雜湊 + 祕密金鑰 → 同時驗證完整性與來源。

### 4.2 數位簽章流程
```
寄件者：訊息 → Hash → 摘要 → 用「寄件者私鑰」加密 → 數位簽章（與訊息一起送出）
收件者：①用「寄件者公鑰」解開簽章得摘要A ②自己把訊息 Hash 得摘要B ③A == B 即驗證成功
```
提供：**完整性、鑑別、不可否認性**；**不提供機密性**（訊息本身沒加密）。

### 4.3 PKI 與數位憑證
- **CA（憑證管理中心）**：用 CA 自己的私鑰簽署「某人的公鑰屬於某人」→ 數位憑證
- 憑證格式：**X.509**；內含持有者資訊、**持有者公鑰**、有效期限、CA 簽章（**不含私鑰**）
- 憑證廢止：CRL（廢止清單）、OCSP（線上查詢）
- 台灣例子：自然人憑證、工商憑證

## 觀念 5：常見攻擊手法

### 5.1 惡意程式
| 類型 | 特徵 |
|---|---|
| **病毒 Virus** | **需寄生**在宿主程式，執行宿主才會感染 |
| **蠕蟲 Worm** | **不需宿主**，可透過網路**自我複製**擴散 |
| **木馬 Trojan** | **偽裝**成正常程式，通常不自我複製，常開後門 |
| **勒索軟體 Ransomware** | 加密受害者檔案，要求贖金 |
| Rootkit | 隱藏自身蹤跡、取得最高權限 |
| 間諜軟體 Spyware | 暗中蒐集資訊（含鍵盤側錄） |
| 殭屍網路 Botnet | 被控制的大量主機，常用來發動 DDoS |

### 5.2 網路與應用程式攻擊
| 攻擊 | 說明 | 防禦 |
|---|---|---|
| **DoS / DDoS** | 大量請求耗盡資源；**SYN Flood** 只送 SYN 不完成三向交握 | 流量清洗、SYN Cookie、CDN |
| **中間人 MITM** | 攔截並可能竄改雙方通訊 | TLS、憑證驗證 |
| **SQL 注入** | 在輸入中插入 SQL 語法，例：`' OR '1'='1` | **參數化查詢（Prepared Statement）**、輸入驗證 |
| **XSS 跨站腳本** | 將惡意 **JavaScript** 注入網頁，在**其他使用者瀏覽器**執行 | 輸出編碼、CSP |
| **CSRF 跨站請求偽造** | 誘使**已登入的使用者**送出非本意的請求 | CSRF Token、SameSite Cookie |
| **緩衝區溢位** | 寫入超過緩衝區大小，覆蓋返回位址 | 邊界檢查、ASLR、DEP |
| **社交工程 / 網路釣魚** | 利用人性弱點騙取資訊 | 教育訓練、MFA |
| 暴力破解 / 字典攻擊 | 嘗試大量密碼 | 帳號鎖定、強密碼、MFA |
| **零時差攻擊 Zero-day** | 利用**尚未修補（甚至尚未公開）**的漏洞 | 縱深防禦、行為偵測 |
| **APT 進階持續性威脅** | 針對特定目標、長期潛伏 | |
| DNS 快取毒化 | 竄改 DNS 快取導向假網站 | DNSSEC |
| ARP 欺騙 | 偽造 ARP 回應進行 MITM | 靜態 ARP、DAI |

## 觀念 6：防禦機制

### 6.1 防火牆
| 類型 | 運作層級 | 說明 |
|---|---|---|
| **封包過濾** | L3/L4 | 依 IP、Port、協定過濾，快但無狀態 |
| **狀態檢測（Stateful）** | L3/L4 | 追蹤連線狀態 |
| **應用層閘道 / 代理** | L7 | 檢查應用層內容，最細緻但最慢 |
| **WAF** | L7 | 專防網頁攻擊（SQL 注入、XSS） |
| NGFW 新世代防火牆 | L3–L7 | 整合 IPS、應用程式辨識 |

### 6.2 IDS vs IPS
- **IDS（入侵偵測）**：被動偵測並**告警**，通常旁路部署。
- **IPS（入侵防禦）**：串接在線上，可**主動阻擋**。
- 偵測方式：**特徵比對（Signature）**——只能抓已知攻擊；**異常偵測（Anomaly）**——可抓未知攻擊但誤報較多。

### 6.3 其他
- **DMZ（非軍事區）**：放置對外服務（Web、Mail Server），隔離內部網路。
- **VPN**：在公共網路建立加密通道；**IPsec**（L3，AH 驗證、ESP 加密）、**SSL/TLS VPN**。
- **TLS**：HTTPS 的基礎，結合非對稱（交換金鑰）+ 對稱（加密資料）+ 雜湊（完整性）。
- **多因素驗證 MFA**：你**知道**的（密碼）、你**擁有**的（手機、Token）、你**本身**的（指紋、臉部）——**兩種不同類別**才算多因素。
- **最小權限原則**、**縱深防禦**、**零信任（Zero Trust）**：永不信任、持續驗證。
- **備份 3-2-1 原則**：3 份資料、2 種不同媒體、1 份異地存放。
- **蜜罐（Honeypot）**：誘捕攻擊者並研究其手法。

<details>
<summary>▶ 參考答案與評分重點</summary>

**Alice 傳送端**（5 分）
1. 對合約 M 做雜湊：H = Hash(M)

2. 用 K 解密得到 M 與 Sig

4. 自己計算 H₂ = Hash(M)
5. H₁ = H₂ → 內容未被竄改，且確實是 Alice 簽署（她無法否認）

評分：每一步金鑰用對是關鍵；說明為何用混合加密（效率）加分。
</details>

## 📝 本章重點速記

- CIA：DDoS → 可用性；竊聽 → 機密性；竄改 → 完整性
- 對稱：DES 56 位元金鑰、AES 128 位元區塊；n(n−1)/2 把金鑰
- 非對稱：RSA 質因數分解、ECC 短金鑰、DH 金鑰交換；2n 把金鑰
- 加密用**收件者公鑰**；簽章用**寄件者私鑰**；簽章不提供機密性
- MD5 128、SHA-1 160、SHA-256 256；Salt 防彩虹表
- 憑證含公鑰不含私鑰；X.509；CA 簽發
- 病毒需宿主、蠕蟲自我複製、木馬偽裝
- SQL 注入 → 參數化查詢；XSS → 注入 JS；CSRF → 冒用已登入身分
- IDS 偵測、IPS 阻擋；DMZ 放對外伺服器；MFA 需不同類別因素
