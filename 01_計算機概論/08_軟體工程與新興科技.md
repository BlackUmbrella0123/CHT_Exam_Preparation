## 觀念 1：軟體開發生命週期與開發模型

**SDLC**：需求分析 → 系統設計 → 實作（程式撰寫）→ 測試 → 部署 → 維護
（**維護階段通常占整體成本最多**）

| 模型 | 特色 | 適用 |
|---|---|---|
| **瀑布式 Waterfall** | 階段依序進行、文件導向，難以回頭修改 | 需求明確且穩定 |
| **雛型 Prototype** | 先做出雛型讓使用者確認需求 | 需求不明確 |
| **螺旋 Spiral** | 每一圈都做**風險分析** | 大型、高風險專案 |
| 增量 Incremental | 分批交付功能 | |
| **V 模型** | 每個開發階段對應一個測試階段 | 重視驗證的系統 |
| **敏捷 Agile** | 短週期迭代、擁抱變更、重視溝通與可運作的軟體 | 需求變動快 |

### 敏捷與 Scrum
- **Scrum 角色**：**Product Owner**（決定需求優先順序）、**Scrum Master**（排除障礙、確保流程）、**開發團隊**
- **衝刺 Sprint**：通常 1–4 週；產品待辦清單（Product Backlog）、衝刺待辦清單（Sprint Backlog）
- 會議：Sprint 規劃會、**每日站立會議（Daily Scrum，約 15 分鐘）**、Sprint 審查會、回顧會
- **極限編程 XP**：結對程式設計、測試驅動開發（**TDD：先寫測試再寫程式**）

### DevOps 與 CI/CD
- **CI 持續整合**：頻繁合併程式並自動建置、測試
- **CD 持續交付/部署**：自動化發布到環境
- 版本控制：**Git**（分散式）

## 觀念 2：軟體測試

### 2.1 測試層級
**單元測試**（單一函式/模組）→ **整合測試**（模組之間的介面）→ **系統測試**（整體功能與非功能需求）→ **驗收測試**（使用者確認）
- **Alpha 測試**：在開發者環境，由使用者測試
- **Beta 測試**：在使用者實際環境
- **回歸測試**：修改程式後，重新測試確認原有功能沒被破壞

### 2.2 黑箱 vs 白箱
| | **黑箱測試** | **白箱測試** |
|---|---|---|
| 依據 | 規格（不看程式碼） | 程式內部結構 |
| 技術 | **等價分割**、**邊界值分析**、因果圖、決策表 | **敘述涵蓋**、**分支涵蓋**、路徑涵蓋、條件涵蓋 |
| 誰做 | 測試人員 | 開發人員 |

- **邊界值分析**：輸入範圍 1~100 → 測 **0、1、100、101**（有時加 2、99）
- 涵蓋強度：路徑涵蓋 > 分支涵蓋 > 敘述涵蓋

### 2.3 循環複雜度（McCabe Cyclomatic Complexity）
$$V(G) = E - N + 2 \quad \text{或} \quad V(G) = \text{判斷節點數} + 1$$
代表**獨立路徑數**，也就是至少需要的測試案例數。

### 2.4 驗證 vs 確認
- **Verification（驗證）**：「我們把產品做**對**了嗎？」（符合規格）
- **Validation（確認）**：「我們做了**對的**產品嗎？」（符合使用者需求）

## 觀念 3：UML 與軟體設計原則

### 3.1 常見 UML 圖
| 圖 | 用途 | 類別 |
|---|---|---|
| **使用案例圖 Use Case** | 描述**使用者（Actor）與系統功能**的互動，用於需求分析 | 行為 |
| **類別圖 Class** | 類別、屬性、方法與類別間的關係 | 結構 |
| **循序圖 Sequence** | 物件間訊息傳遞的**時間順序** | 互動 |
| 活動圖 Activity | 流程，類似流程圖 | 行為 |
| 狀態圖 State | 物件在不同事件下的狀態轉換 | 行為 |
| 元件圖 / 部署圖 | 系統元件與實體部署 | 結構 |

類別圖關係：繼承（空心三角箭頭）、實作（虛線空心三角）、**聚合**（空心菱形，整體與部分可獨立存在）、**組合**（實心菱形，部分隨整體消滅）、關聯、相依。

### 3.2 設計原則
- **高內聚（High Cohesion）、低耦合（Low Coupling）** ← 必考
- **SOLID**：單一職責、開放封閉（對擴充開放、對修改封閉）、里氏替換、介面隔離、依賴反轉
- **MVC**：Model（資料與邏輯）、View（畫面）、Controller（接收輸入、協調）

### 3.3 常見設計模式
| 模式 | 用途 |
|---|---|
| **Singleton 單例** | 確保類別**只有一個實例** |
| Factory 工廠 | 將物件建立過程封裝 |
| **Observer 觀察者** | 一對多通知（訂閱/發布） |
| Adapter 轉接器 | 轉換介面使不相容的類別可合作 |
| Strategy 策略 | 執行期切換演算法 |

## 觀念 4：雲端運算與虛擬化

### 4.1 NIST 定義的五大特性
**隨需自助服務、廣泛網路存取、資源共享（池化）、快速彈性、可量測的服務（依用量計費）**

### 4.2 服務模式（必考）
| 模式 | 雲端提供到哪裡 | 使用者管理 | 例子 |
|---|---|---|---|
| **IaaS** 基礎設施即服務 | 伺服器、儲存、網路、虛擬化 | OS、執行環境、應用程式、資料 | **AWS EC2**、GCE、Azure VM、中華電信 hicloud |
| **PaaS** 平台即服務 | + OS、執行環境、中介軟體 | 應用程式、資料 | **Google App Engine**、Heroku、Azure App Service |
| **SaaS** 軟體即服務 | 全部 | 只用軟體 | **Gmail**、Google Docs、Microsoft 365、Salesforce |

> 記憶：IaaS 給你「機器」、PaaS 給你「平台」、SaaS 給你「軟體」。

### 4.3 部署模式
公有雲、私有雲、**混合雲**、社群雲。

### 4.4 虛擬化與容器
- **Hypervisor Type 1（裸機型）**：直接跑在硬體上，例：VMware ESXi、Hyper-V、KVM
- **Hypervisor Type 2（寄居型）**：跑在作業系統上，例：VirtualBox、VMware Workstation
- **容器（Container）**：**共用主機 OS 核心**，比 VM 更輕量、啟動快；**Docker** 打包容器，**Kubernetes（K8s）** 負責容器編排
- **邊緣運算（Edge Computing）**：在靠近資料來源處運算，降低延遲與頻寬負擔
- **Serverless（無伺服器）**：只寫函式，依呼叫計費（例：AWS Lambda）

## 觀念 5：人工智慧與機器學習

### 5.1 機器學習三大類
| 類型 | 資料 | 任務 | 例子 |
|---|---|---|---|
| **監督式學習** | **有標籤** | 分類、迴歸 | 垃圾郵件分類、房價預測；決策樹、SVM、KNN |
| **非監督式學習** | **無標籤** | 分群、降維 | 客群分群；**K-means**、PCA |
| **強化學習** | 與環境互動、獲得**獎勵** | 決策 | AlphaGo、機器人控制 |

### 5.2 深度學習
- **CNN（卷積神經網路）**：擅長**影像**辨識（卷積層、池化層）
- **RNN / LSTM**：處理**序列**資料（語音、時間序列）
- **Transformer**：以**自注意力（Self-Attention）** 為核心，是 **GPT、BERT 等大型語言模型（LLM）** 的基礎
- **生成式 AI**：GAN（生成對抗網路）、擴散模型、LLM
- **過擬合（Overfitting）**：訓練資料表現好、測試資料表現差 → 解法：更多資料、正則化、Dropout、提早停止、交叉驗證

### 5.3 混淆矩陣與評估指標
|  | 預測為正 | 預測為負 |
|---|---|---|
| **實際為正** | TP | FN |
| **實際為負** | FP | TN |

- **準確率 Accuracy** = (TP + TN) / 全部
- **精確率 Precision** = TP / (TP + FP)　← 預測為正的有多少是對的
- **召回率 Recall** = TP / (TP + FN)　← 實際為正的抓到多少
- **F1** = 2 × P × R / (P + R)

## 觀念 6：5G、SDN、IoT、大數據與區塊鏈（電信業熱門）

### 6.1 5G 三大應用情境
| 情境 | 全名 | 特色 | 應用 |
|---|---|---|---|
| **eMBB** | 增強型行動寬頻 | **高速率** | 4K/8K 串流、AR/VR |
| **URLLC** | 超可靠低延遲通訊 | **低延遲（~1 ms）、高可靠** | 自駕車、遠端手術、工業控制 |
| **mMTC** | 大規模機器型通訊 | **大量連線**（每平方公里百萬裝置） | 物聯網、智慧城市 |

5G 關鍵技術：**Massive MIMO**、**毫米波（mmWave）**、波束成形、**網路切片（Network Slicing）**——在同一實體網路上切出多個虛擬網路，各自滿足不同情境需求；**MEC（多接取邊緣運算）**。

### 6.2 SDN 與 NFV
- **SDN（軟體定義網路）**：**控制平面與資料平面分離**，由集中式控制器管理；常用協定 **OpenFlow**。
- **NFV（網路功能虛擬化）**：把防火牆、路由器等網路功能用**軟體跑在通用伺服器**上，取代專用硬體。

### 6.3 物聯網 IoT
- 三層架構：**感知層**（感測器、RFID）→ **網路層**（傳輸）→ **應用層**
- 低功耗廣域網路（LPWAN）：**NB-IoT**（電信業者授權頻段）、LoRa、Sigfox
- 短距：藍牙 BLE、Zigbee、**RFID / NFC**（NFC 距離約 10 公分內，用於行動支付）

### 6.4 大數據
- **5V**：Volume（量大）、Velocity（速度快）、Variety（多樣）、Veracity（真實性）、Value（價值）
- **Hadoop**：**HDFS**（分散式檔案系統）+ **MapReduce**（分散式運算）；**Spark** 以記憶體運算，比 MapReduce 快

### 6.5 區塊鏈
- 去中心化、**不可竄改**（每個區塊含前一區塊的雜湊值）、可追溯
- 共識機制：**PoW 工作量證明**（比特幣，耗能）、**PoS 權益證明**（以太坊現行）
- 智能合約（Smart Contract）：以太坊
