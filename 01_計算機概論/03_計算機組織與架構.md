## 觀念 1：電腦五大單元與范紐曼架構

### 1.1 五大單元
**輸入單元、輸出單元、記憶單元、算術邏輯單元（ALU）、控制單元（CU）**
其中 **ALU + CU（+ 暫存器）= CPU**。

### 1.2 范紐曼架構（Von Neumann）
- **內儲程式（Stored Program）**：程式與資料都存放在同一個記憶體中。
- 指令**循序執行**（由程式計數器 PC 決定下一道指令）。
- 缺點：**范紐曼瓶頸**——CPU 與記憶體之間只有一條通道，速度受限。
- 對照：**哈佛架構（Harvard）** 將指令記憶體與資料記憶體分開，可同時存取（常見於 DSP、微控制器，以及 CPU 內的 L1 指令/資料快取分離）。

### 1.3 重要暫存器
| 暫存器 | 功能 |
|---|---|
| **PC**（程式計數器） | 存放**下一道**要執行指令的位址 |
| **IR**（指令暫存器） | 存放**目前**正在執行的指令 |
| **MAR**（記憶體位址暫存器） | 存放要存取的記憶體**位址** |
| **MDR / MBR**（記憶體資料暫存器） | 存放從記憶體讀出或要寫入的**資料** |
| ACC（累加器） | 存放 ALU 的運算結果 |
| PSW / Flag | 狀態旗標：零（Z）、進位（C）、溢位（V）、負（N） |

## 觀念 2：指令週期、ISA 與定址模式

### 2.1 指令週期（Instruction Cycle）
1. **擷取（Fetch）**：MAR ← PC；MDR ← Memory[MAR]；IR ← MDR；PC ← PC + 1
2. **解碼（Decode）**：控制單元分析 IR 中的運算碼（opcode）
3. **執行（Execute）**：ALU 運算或存取記憶體
4. （寫回 / 中斷檢查）

> 機器週期 = 擷取週期 + 執行週期；**中斷**通常在一道指令執行完後才檢查。

### 2.2 CISC vs RISC
| | CISC | RISC |
|---|---|---|
| 指令數量 | 多、複雜 | 少、簡單 |
| 指令長度 | 不固定 | **固定** |
| 每指令時脈數 CPI | 多 | 接近 1 |
| 記憶體存取 | 多數指令可存取記憶體 | **只有 Load / Store** 可存取記憶體 |
| 暫存器 | 較少 | 較多 |
| 管線化 | 較難 | **容易** |
| 代表 | x86 | ARM、RISC-V、MIPS |

### 2.3 定址模式（Addressing Mode）
| 模式 | 運算元從哪裡來 | 範例 |
|---|---|---|
| **立即** Immediate | 運算元就在指令中 | `ADD R1, #5` |
| **直接** Direct | 指令中是運算元的**記憶體位址** | `LOAD R1, 1000` |
| **間接** Indirect | 指令中位址所指的內容**才是**運算元位址 | `LOAD R1, (1000)` |
| **暫存器** Register | 運算元在暫存器中 | `ADD R1, R2` |
| 暫存器間接 | 暫存器內容是運算元位址 | `LOAD R1, (R2)` |
| **索引** Indexed | 有效位址 = 基底 + 索引暫存器 | 陣列存取 |
| **相對** Relative | 有效位址 = PC + 位移量 | 分支跳躍 |

> 存取速度：立即 > 暫存器 > 直接 > 間接（間接要存取記憶體兩次）。

## 觀念 3：CPU 效能計算

### 3.1 核心公式（必背）
$$\text{CPU 時間} = \text{指令數 IC} × \text{CPI} × \text{時脈週期} = \frac{\text{IC} × \text{CPI}}{\text{時脈頻率}}$$

$$\text{MIPS} = \frac{\text{時脈頻率}}{\text{CPI} × 10^6}$$

- 時脈週期 = 1 / 時脈頻率（2 GHz → 0.5 ns）
- 平均 CPI = Σ（各類指令比例 × 該類 CPI）

### 3.2 Amdahl 定律
程式中比例 **f** 的部分加速 **S** 倍，整體加速比：
$$\text{Speedup} = \frac{1}{(1 - f) + \dfrac{f}{S}}$$
> 意義：無法加速的部分決定了上限。即使 S → ∞，最大加速比 = 1 / (1 − f)。

## 觀念 4：管線（Pipeline）

### 4.1 經典五級管線
**IF（擷取）→ ID（解碼）→ EX（執行）→ MEM（存取記憶體）→ WB（寫回）**

### 4.2 管線時間公式
k 級管線執行 n 道指令（每級 1 個週期）：
$$\text{總週期數} = k + (n - 1)$$
未管線化：k × n。加速比 = kn / (k + n − 1)，n 很大時趨近於 **k**。

> 若各級時間不同，**時脈週期取決於最慢的那一級**。

### 4.3 管線危障（Hazards）
| 危障 | 原因 | 解法 |
|---|---|---|
| **結構危障** | 硬體資源衝突（例如同時存取同一記憶體） | 增加硬體、指令/資料快取分離 |
| **資料危障** | 後面指令需要前面指令尚未寫回的結果（RAW） | **資料前推（forwarding / bypassing）**、插入停頓（stall / bubble）、指令重排 |
| **控制危障** | 分支指令導致不確定下一道指令 | **分支預測**、延遲分支、停頓 |

## 觀念 5：記憶體階層與快取

### 5.1 記憶體階層（由快到慢、由小到大、由貴到便宜）
**暫存器 → L1 快取 → L2 → L3 → 主記憶體（DRAM）→ SSD → HDD → 磁帶/雲端**

| 類型 | 特性 |
|---|---|
| **SRAM** | 正反器構成、快、貴、**不需刷新** → 用於**快取** |
| **DRAM** | 電容構成、密度高、便宜、**需刷新** → 用於**主記憶體** |
| ROM / Flash | **非揮發性**，斷電資料仍在（BIOS/UEFI、SSD） |
| RAM | **揮發性**，斷電資料消失 |

### 5.2 區域性原理（快取有效的原因）
- **時間區域性**：剛被存取的資料，很快會再被存取（例：迴圈變數）。
- **空間區域性**：被存取資料附近的資料，很快也會被存取（例：循序走訪陣列）。

### 5.3 快取映射方式
| 方式 | 說明 | 優缺點 |
|---|---|---|
| **直接映射** | 每個區塊只能放到**固定一個**快取行（行號 = 區塊號 mod 行數） | 簡單快速，但衝突失誤多 |
| **完全關聯** | 可放到**任何**快取行 | 命中率高，但比對硬體昂貴 |
| **集合關聯（k-way）** | 先映射到固定的「集合」，集合內任意放 | 折衷，最常用 |

**直接映射的位址切分**：`| Tag | Index | Offset |`
- Offset 位元數 = log₂(區塊大小)
- Index 位元數 = log₂(快取行數)
- Tag = 位址總位元數 − Index − Offset

### 5.4 平均存取時間（EAT）
$$\text{EAT} = h × T_c + (1 - h) × (T_c + T_m)$$
（h：命中率；T_c：快取時間；T_m：主記憶體時間。若題目說「失誤時直接存取主記憶體」，則改用 h×T_c + (1−h)×T_m，**看題目定義**。）

### 5.5 寫入策略
- **Write-through（寫穿）**：同時寫入快取與主記憶體，一致性好但慢。
- **Write-back（寫回）**：只寫快取，被替換時才寫回（需要 dirty bit），較快。

## 觀念 6：I/O 與儲存裝置

### 6.1 I/O 方式
| 方式 | 說明 | CPU 負擔 |
|---|---|---|
| **輪詢（Polling）** | CPU 不斷檢查裝置狀態 | 最高（忙碌等待） |
| **中斷（Interrupt）** | 裝置完成後發中斷通知 CPU | 中 |
| **DMA**（直接記憶體存取） | DMA 控制器直接在裝置與記憶體間搬資料，**完成後才中斷 CPU** | 最低，適合大量資料 |

### 6.2 匯流排（Bus）
- **資料匯流排**：雙向，寬度決定一次傳輸量。
- **位址匯流排**：單向（CPU → 記憶體），寬度決定**可定址空間**（n 條 → 2ⁿ）。
- **控制匯流排**：讀/寫、中斷等控制訊號。

### 6.3 硬碟存取時間
**存取時間 = 搜尋時間（seek）+ 旋轉延遲（rotational latency）+ 傳輸時間**
平均旋轉延遲 = 轉半圈的時間 = ½ × (60 / RPM) 秒。

### 6.4 RAID
| 等級 | 方式 | 容錯 | N 顆容量 C 的可用空間 |
|---|---|---|---|
| RAID 0 | 條帶化（striping） | **無** | N × C |
| RAID 1 | 鏡像（mirroring） | 可壞 1 顆 | C（N=2 時為一半） |
| RAID 5 | 條帶 + **分散式同位元** | 可壞 1 顆 | (N − 1) × C |
| RAID 6 | 條帶 + 雙同位元 | 可壞 2 顆 | (N − 2) × C |
| RAID 10 | 先鏡像再條帶 | 每組鏡像可壞 1 顆 | N × C / 2 |

## 📝 本章重點速記

- PC = 下一道指令位址；IR = 目前指令；MAR = 位址；MDR = 資料
- CPU 時間 = IC × CPI / 頻率；MIPS = 頻率 / (CPI × 10⁶)
- Amdahl：1 / ((1−f) + f/S)
- 管線：k + n − 1 個週期；時脈取最慢級；三種危障（結構/資料/控制）
- RISC：固定長度、Load/Store、易管線化
- 快取 SRAM、主記憶體 DRAM；時間 vs 空間區域性
- 直接映射位址：Tag | Index | Offset
- EAT = h·Tc + (1−h)(Tc + Tm)
- DMA 負擔最低；平均旋轉延遲 = 半圈時間；RAID 5 可用 (N−1)
