# 中華電信 資訊類 專業科目 自學課程

本課程依兩個考科設計，**每一個觀念後面緊接著配套練習題**，答案與詳解收在可展開的「▶ 解答」區塊中，請先作答再展開。

> 中華電信招考的專業科目大多是**四選一的選擇題**，題目偏重「觀念判斷」與「程式碼追蹤（trace）」。因此本課程的練習題以選擇題為主，再搭配需要手算的計算題與程式追蹤題。
>
> ⚠️ 正式考試範圍、題型與配分以當年度**招考簡章**為準，報名後請先核對一次。

## ✍️ 使用方式

1. 讀一個觀念 → 立刻做該觀念的練習題 → 展開解答對答案。
2. 錯的題目在題號前標記 `❌`，第二輪只複習打叉的題。
3. 程式追蹤題請**一定要在紙上畫變數表**，不要用心算，考場上最容易在這裡失分。
4. 每章後段有「✍️ 非選擇題實戰」：在空白的程式碼區塊中寫下你的答案（可直接在 Markdown 裡編輯），寫完再展開「參考答案與評分重點」自行評分。
5. 每章最後有「本章重點速記」，考前一週只看這些即可。

## 📋 考試題型（依中華電信 101～103 年試卷）

| 題型 | 題數 | 配分 |
|---|---|---|
| 四選一單選題 | 60 題 | 每題 1 分，共 60 分 |
| 非選擇題 | 4 題 | 每題 10 分，共 40 分 |

非選擇題占 **40%**，一定要練習「寫出完整過程」，不能只會選答案。另外第二科歷年名稱為「程式設計概論**及資料庫管理**」，資料庫章節（01_計算機概論/06）也要算進第二科的準備範圍。
