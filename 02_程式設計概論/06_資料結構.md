## 觀念 1：堆疊（Stack）與佇列（Queue）

### 1.1 比較
| | **堆疊 Stack** | **佇列 Queue** |
|---|---|---|
| 特性 | **LIFO** 後進先出 | **FIFO** 先進先出 |
| 操作 | push（放入頂端）、pop（取出頂端）、top/peek | enqueue（加到尾端 rear）、dequeue（從前端 front 取出） |
| 應用 | **函式呼叫、遞迴**、括號配對、運算式求值、**DFS**、復原（Undo）、瀏覽器上一頁 | 排程、**BFS**、印表機工作、緩衝區 |

### 1.2 環狀佇列（Circular Queue）
- 用陣列實作，大小為 n，`rear = (rear + 1) % n`
- 常見判斷法（犧牲一格）：
  - **空**：`front == rear`
  - **滿**：`(rear + 1) % n == front` → **最多只能存 n − 1 個元素**
- 其他變形：**雙向佇列（Deque）** 兩端皆可進出；**優先佇列** 依優先權出列（用堆積實作）

### 1.3 堆疊輸出序列
依序 push 1, 2, …, n（中間可任意 pop），可能的 pop 序列數 = **卡塔蘭數 Cₙ = C(2n, n) / (n+1)**
n = 3 → **5** 種；n = 4 → **14** 種
**判斷技巧**：某數 x 被 pop 時，所有比 x 小、但還在堆疊裡的數，之後必須**由大到小**出來。

## 觀念 2：運算式轉換與求值

### 2.1 三種表示法
| 表示法 | 運算子位置 | 例：A + B |
|---|---|---|
| 中序 Infix | 中間 | `A + B` |
| **前序 Prefix（波蘭式）** | 前面 | `+ A B` |
| **後序 Postfix（逆波蘭式）** | 後面 | `A B +` |

### 2.2 快速轉換法：加括號法
1. 依優先順序**把每個運算完整加上括號**
2. 後序：把每個運算子**移到它所屬括號的右括號處**；前序：移到左括號處
3. 刪除所有括號

例：`A + B * C - D / E`
```
加括號：((A + (B * C)) - (D / E))
後序：A B C * + D E / -
前序：- + A * B C / D E
```

### 2.3 後序式求值（用堆疊）
從左到右掃描：**遇到數字 push；遇到運算子 pop 兩個**（先 pop 的是**右**運算元），運算後 push 回去。

例：`5 3 2 * + 4 -`
```
5 → [5]
3 → [5,3]
2 → [5,3,2]
* → 3*2=6 → [5,6]
+ → 5+6=11 → [11]
4 → [11,4]
- → 11-4=7 → [7]   答案 7
```

## 觀念 3：鏈結串列（Linked List）

### 3.1 陣列 vs 鏈結串列
| | 陣列 | 鏈結串列 |
|---|---|---|
| 記憶體 | 連續 | 不連續（用指標串起來） |
| 隨機存取第 k 個 | **O(1)** | **O(n)** |
| 插入 / 刪除（已知位置） | O(n)（要搬移） | **O(1)**（改指標） |
| 大小 | 固定（靜態） | 動態 |
| 額外空間 | 無 | 每個節點需存指標 |

### 3.2 種類
- **單向**：每個節點有 `data` 與 `next`
- **雙向**：多一個 `prev`，可往回走，刪除時不需找前一個節點
- **環狀**：最後一個節點指回第一個

### 3.3 基本操作（C）
```c
struct Node { int data; struct Node *next; };

/* 在節點 p 之後插入 q —— 順序不能顛倒！ */
q->next = p->next;
p->next = q;

/* 刪除 p 之後的節點 */
struct Node *t = p->next;
p->next = t->next;
free(t);

/* 反轉單向串列 */
struct Node *prev = NULL, *cur = head, *nxt;
while (cur != NULL) {
    nxt = cur->next;
    cur->next = prev;
    prev = cur;
    cur = nxt;
}
head = prev;
```

## 觀念 4：樹與二元樹

### 4.1 名詞
- **分支度（degree）**：節點的子節點數；**樹葉（leaf）**：分支度為 0
- **階層（level）**：根為第 1 層（有些書從 0 開始，看題目）
- **高度（height / depth）**：最大階層數
- n 個節點的樹有 **n − 1** 條邊

### 4.2 二元樹性質（根在第 1 層）
| 性質 | 公式 |
|---|---|
| 第 i 層最多節點數 | **2ⁱ⁻¹** |
| 高度 h 最多節點數 | **2ʰ − 1** |
| n 個節點的最小高度 | **⌈log₂(n + 1)⌉** |
| 樹葉數 n₀ 與分支度 2 的節點數 n₂ | **n₀ = n₂ + 1** |
| n 個節點可形成的不同二元樹 | 卡塔蘭數 Cₙ |

- **滿二元樹（Full / Perfect）**：高度 h 剛好有 2ʰ − 1 個節點
- **完整二元樹（Complete）**：除了最後一層外全滿，最後一層**由左到右**連續填
- **歪斜樹（Skewed）**：所有節點只有左（或右）子

### 4.3 以陣列表示（索引從 1 開始）
節點 i 的**父節點 ⌊i/2⌋**、**左子 2i**、**右子 2i + 1**（適合完整二元樹；歪斜樹會浪費大量空間）

## 觀念 5：二元樹走訪

| 走訪 | 順序 | 口訣 |
|---|---|---|
| **前序 Preorder** | **根** → 左 → 右 | 根在前 |
| **中序 Inorder** | 左 → **根** → 右 | 根在中 |
| **後序 Postorder** | 左 → 右 → **根** | 根在後 |
| **階層 Level-order** | 由上到下、由左到右 | 用**佇列** |

### 範例樹
```
          A
        /   \
       B     C
      / \     \
     D   E     F
        /
       G
```
- 前序：**A B D E G C F**
- 中序：**D B G E A C F**
- 後序：**D G E B F C A**
- 階層：**A B C D E F G**

### 由走訪結果重建二元樹
- **前序 + 中序** 或 **後序 + 中序** → 可唯一決定
- **前序 + 後序** → **無法**唯一決定
- 方法：前序第一個（或後序最後一個）是根 → 在中序中找到根，左邊是左子樹、右邊是右子樹 → 遞迴

### 運算式樹
樹葉是運算元、內部節點是運算子：**中序 → 中序式，前序 → 前序式，後序 → 後序式**

## 觀念 6：二元搜尋樹（BST）、AVL 樹與堆積（Heap）

### 6.1 BST
- 規則：**左子樹所有值 < 根 < 右子樹所有值**
- **中序走訪 BST → 得到由小到大排序的結果**
- 搜尋 / 插入 / 刪除：平均 **O(log n)**，最差（歪斜）**O(n)**
- 刪除有兩個子節點的節點：以**中序後繼者（右子樹最小值）**或**中序前行者（左子樹最大值）**取代

### 6.2 AVL 樹
- **平衡因子 = 左子樹高 − 右子樹高**，每個節點都必須是 **−1、0、1**
- 插入後若失衡，以旋轉修正：LL、RR（單旋轉）、LR、RL（雙旋轉）
- 保證高度 O(log n) → 操作皆 **O(log n)**
- 其他平衡樹：紅黑樹（Java TreeMap、C++ std::map）、B 樹 / B+ 樹（資料庫索引）

### 6.3 堆積（Heap）
- **最大堆積**：每個節點 ≥ 子節點（根最大）；**最小堆積**反之
- 是一棵**完整二元樹**，以**陣列**儲存
- **插入**：放在最後，再**往上**與父節點比較交換（sift-up）→ O(log n)
- **刪除根**：把最後一個元素移到根，再**往下**與較大的子節點交換（sift-down）→ O(log n)
- 由 n 個元素建立堆積（由下而上 heapify）：**O(n)**
- 用途：**優先佇列**、**堆積排序**

## 觀念 7：圖形（Graph）

### 7.1 名詞與性質
- 無向圖 / 有向圖；加權圖
- **無向完全圖 n 個頂點有 n(n−1)/2 條邊**；有向完全圖有 n(n−1) 條
- **所有頂點分支度總和 = 2 × 邊數**（無向圖）
- 連通圖、**樹 = 連通且無迴路，n 個頂點有 n − 1 條邊**
- **DAG**：有向無迴路圖

### 7.2 表示法
| | **相鄰矩陣** | **相鄰串列** |
|---|---|---|
| 空間 | **O(V²)** | **O(V + E)** |
| 判斷兩點是否相鄰 | O(1) | O(degree) |
| 適合 | **稠密圖** | **稀疏圖** |
| 無向圖的矩陣 | 對稱 | |

### 7.3 走訪
| | **DFS 深度優先** | **BFS 廣度優先** |
|---|---|---|
| 資料結構 | **堆疊**（或遞迴） | **佇列** |
| 特性 | 一路走到底再回頭 | 一層一層往外 |
| 應用 | 找連通元件、拓樸排序、偵測迴路 | **無權重圖的最短路徑** |
| 時間（相鄰串列） | O(V + E) | O(V + E) |

### 7.4 拓樸排序（Topological Sort）
適用於 **DAG**：反覆選出**入分支度為 0** 的頂點輸出並移除，結果可能不唯一。（用於課程先修、工作排程）

### 範例圖（無向，相鄰點依字母順序拜訪）
```
A — B
|    |
C — D
|    |
E — F
```
邊：A-B、A-C、B-D、C-D、C-E、D-F、E-F

## 觀念 8：雜湊（Hashing）

### 8.1 基本概念
- 透過**雜湊函數** h(key) 直接算出儲存位置，理想搜尋時間 **O(1)**
- 常用函數：**除法 h(k) = k mod m**（m 最好取**質數**）、平方取中、摺疊法
- **碰撞（Collision）**：不同 key 算出相同位置
- **負載因子 α = n / m**（資料數 / 表格大小）；α 越大，碰撞越多

### 8.2 碰撞處理
| 方法 | 說明 |
|---|---|
| **線性探測 Linear Probing** | 往下一格找：h, h+1, h+2, …（會產生**群聚 clustering**） |
| 二次探測 Quadratic Probing | h + 1², h + 2², h + 3², … |
| 雙重雜湊 Double Hashing | 用第二個雜湊函數決定跳距 |
| **鏈結法 Chaining** | 每個位置掛一條鏈結串列，α 可以 > 1 |

<summary>▶ 參考答案與評分重點</summary>

```c
#include <ctype.h>

int evalPostfix(const char *exp) {
    int stack[100], top = -1;
    for (; *exp != '\0'; exp++) {
        if (isdigit((unsigned char)*exp)) {
            stack[++top] = *exp - '0';          /* push */
        } else {
            int b = stack[top--];               /* 先 pop 的是右運算元 */
            int a = stack[top--];
            switch (*exp) {
                case '+': stack[++top] = a + b; break;
                case '-': stack[++top] = a - b; break;
                case '*': stack[++top] = a * b; break;
                case '/': stack[++top] = a / b; break;
            }
        }
    }
    return stack[top];
}
```
過程：
| 讀入 | 堆疊 |
|---|---|
| 2 | [2] |
| 3 | [2, 3] |
| * | [6] |
| 5 | [6, 5] |
| 4 | [6, 5, 4] |
| * | [6, 20] |
| + | [26] |
| 9 | [26, 9] |
| − | [17] |

結果 **17**。
評分：push / pop 正確（4 分）；**運算元順序**（b 先 pop）（2 分）；字元轉數字 `- '0'`（2 分）；過程表（2 分）。

## 📝 本章重點速記

- Stack LIFO（遞迴、DFS、括號、運算式）；Queue FIFO（BFS、排程）
- 環狀佇列滿：(rear+1) % n == front，存 n−1 個；pop 序列數 = 卡塔蘭數（3→5、4→14）
- 中轉後序：加括號、運算子移到右括號；後序求值：數字 push、運算子 pop 兩個（先 pop 的是右運算元）
- 鏈結串列：存取 O(n)、插刪 O(1)；插入先接後面再接前面
- 二元樹：第 i 層 ≤ 2ⁱ⁻¹、高 h ≤ 2ʰ−1、n₀ = n₂ + 1；陣列父 ⌊i/2⌋、子 2i, 2i+1
- 前中後序看「根」的位置；前序 + 後序不能唯一決定樹
- BST 中序 = 排序；最差 O(n)；AVL 平衡因子 −1~1
- Heap：插入往上、刪根往下，O(log n)；建堆 O(n)
- 完全圖邊數 n(n−1)/2；分支度總和 = 2E；矩陣 O(V²) 適合稠密、串列 O(V+E) 適合稀疏
- DFS 用堆疊、BFS 用佇列（無權最短路）；拓樸排序用於 DAG
- 雜湊 k mod 質數；線性探測有群聚；鏈結法 α 可 > 1
