## 觀念 1：函式基礎

```c
int add(int a, int b);          // 函式原型（宣告）：讓編譯器先知道介面

int main() {
    int s = add(3, 4);          // 呼叫：3、4 是「實際參數 (argument)」
    printf("%d", s);
}

int add(int a, int b) {         // 定義：a、b 是「形式參數 (parameter)」
    return a + b;
}
```
- `void`：不回傳值的函式。
- `return` 會**立即結束**函式。
- 呼叫函式時，系統在**堆疊（Stack）**上建立「活動紀錄（Activation Record / Stack Frame）」，存放參數、區域變數、返回位址。

## 觀念 2：參數傳遞方式

### 2.1 三種主要方式
| 方式 | 說明 | 函式內修改是否影響呼叫端 | 語言 |
|---|---|---|---|
| **傳值 Call by Value** | 複製一份值給形式參數 | **不會** | C、Java（基本型別） |
| **傳址 Call by Address** | 傳入變數的**位址**（指標），用 `*` 修改 | **會** | C |
| **傳參考 Call by Reference** | 形式參數是實際參數的**別名** | **會** | C++（`int &x`） |

```c
void swap1(int a, int b)   { int t = a; a = b; b = t; }      // 無效
void swap2(int *a, int *b) { int t = *a; *a = *b; *b = t; }  // 有效，呼叫 swap2(&x, &y)
```
```cpp
void swap3(int &a, int &b) { int t = a; a = b; b = t; }      // C++ 有效，呼叫 swap3(x, y)
```

### 2.2 Java 與 Python
- **Java 一律傳值**：基本型別傳值的副本；物件則是傳「參考的副本」——可以透過它**修改物件內容**，但**讓參數指向新物件不會影響呼叫端**。
- **Python**：傳「物件參考」。可變物件（list、dict）在函式內修改內容會影響外面；不可變物件（int、str、tuple）則不會。

### 2.3 其他傳遞方式（偶爾考）
- **傳值-結果 Call by Value-Result（Copy-in/Copy-out）**：進入時複製值，**結束時再把值複製回去**。
- **傳名 Call by Name**：參數在每次使用時才以文字代換後求值（ALGOL）。

### 經典比較題
```
procedure p(x, y) { x = x + 1; y = y + x; }
a = 1;  p(a, a);  print a;
```
| 方式 | 過程 | a |
|---|---|---|
| 傳值 | x、y 都是副本 | **1** |
| 傳參考 | x、y 都是 a 的別名：a = 2；a = 2 + 2 = 4 | **4** |
| 傳值-結果（由左到右複製回去） | x=1,y=1 → x=2 → y=1+2=3 → 先寫回 x(2) 再寫回 y(3) | **3** |

## 觀念 3：變數範圍與生命週期

| 種類 | 宣告位置 | 範圍（可見區） | 生命週期 | 未初始化的值 |
|---|---|---|---|---|
| **區域變數** | 函式 / 區塊內 | 該區塊 | 區塊結束即消失（Stack） | **不確定（垃圾值）** |
| **全域變數** | 所有函式外 | 整個檔案（宣告之後） | 整個程式執行期間 | **0** |
| **static 區域變數** | 函式內加 `static` | 該函式 | **整個程式執行期間**，值會保留 | **0** |

- **遮蔽（Shadowing）**：內層與外層同名時，內層變數會遮住外層。
- `static` 全域變數 / 函式：限制只能在**該檔案**內使用。
- **靜態範圍（Static/Lexical Scope）**：依程式碼「寫在哪」決定變數綁定（C、Java、Python 皆是）。**動態範圍**：依「呼叫順序」決定（早期 Lisp、Bash）。

## 觀念 4：遞迴基礎

遞迴函式 = **終止條件（Base Case）** + **遞迴呼叫（往終止條件逼近）**
缺少終止條件 → 無限遞迴 → **堆疊溢位（Stack Overflow）**。

```c
int sum(int n) {          // 1 + 2 + ... + n
    if (n == 0) return 0;         // 終止條件
    return n + sum(n - 1);        // 遞迴
}
```
展開：sum(3) = 3 + sum(2) = 3 + 2 + sum(1) = 3 + 2 + 1 + sum(0) = 6

### 印出順序：「先遞迴再印」 vs 「先印再遞迴」
```c
void up(int n)   { if (n > 0) { up(n - 1);  printf("%d", n); } }   // up(3)   → 123
void down(int n) { if (n > 0) { printf("%d", n); down(n - 1); } }  // down(3) → 321
```

## 觀念 5：進階遞迴追蹤

### 5.1 費氏數列與呼叫次數
```c
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```
呼叫次數 C(n) = C(n−1) + C(n−2) + 1，C(0) = C(1) = 1
| n | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| fib(n) | 0 | 1 | 1 | 2 | 3 | 5 | 8 |
| 呼叫次數 | 1 | 1 | 3 | 5 | 9 | **15** | 25 |

時間複雜度 **O(2ⁿ)**（大量重複計算）→ 用**記憶化（Memoization）**或**動態規劃**改善為 O(n)。

### 5.2 河內塔
```c
void hanoi(int n, char from, char via, char to) {
    if (n == 1) { printf("%c->%c\n", from, to); return; }
    hanoi(n - 1, from, to, via);
    printf("%c->%c\n", from, to);
    hanoi(n - 1, via, from, to);
}
```
搬移次數 T(n) = 2T(n−1) + 1 = **2ⁿ − 1**

## 觀念 6：遞迴 vs 迭代

| | 遞迴 | 迭代（迴圈） |
|---|---|---|
| 程式碼 | 簡潔、接近數學定義 | 較長 |
| 記憶體 | 每次呼叫占用堆疊，可能溢位 | 較省 |
| 速度 | 有函式呼叫的額外負擔 | 較快 |
| 適合 | 樹、圖走訪、分治、回溯 | 簡單重複 |

- **任何遞迴都可以改寫成迭代**（必要時自己用堆疊模擬）。
- **尾端遞迴（Tail Recursion）**：遞迴呼叫是函式的**最後一個動作**，編譯器可最佳化成迴圈，不增加堆疊深度。
  ```c
  int fact(int n, int acc) { if (n <= 1) return acc; return fact(n - 1, n * acc); }  // 尾端遞迴
  ```

int gcd(int a, int b) {
