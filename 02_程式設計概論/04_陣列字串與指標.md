## 觀念 1：一維陣列

```c
int a[5];                 // 索引 0 ~ 4
int b[5] = {1, 2};        // 未指定的元素自動補 0 → {1, 2, 0, 0, 0}
int c[]  = {3, 1, 4};     // 長度由初始值決定 → 3
int n = sizeof(c) / sizeof(c[0]);   // 計算元素個數 = 3
```
- **陣列名稱代表第一個元素的位址**：`a` 等同 `&a[0]`。
- C **不檢查陣列越界**：`a[5]` 不會報錯，但屬於未定義行為（可能改到別的變數或當機）。
- 陣列傳入函式時會**退化成指標**，在函式內 `sizeof(arr)` 得到的是**指標大小**，不是陣列大小 → 需另外傳長度。
- 陣列不能整個用 `=` 指定（`a = b;` 錯誤），要逐一複製或用 `memcpy`。

## 觀念 2：二維陣列與位址計算（必考計算）

### 2.1 宣告
```c
int m[2][3] = { {1, 2, 3},
                {4, 5, 6} };    // m[1][2] = 6
```

### 2.2 記憶體排列方式
- **列優先（Row-major）**：一列一列存。**C、C++、Java、Python（NumPy 預設）**
- **行優先（Column-major）**：一行一行存。**Fortran、MATLAB**

### 2.3 位址公式
陣列 `A[l₁..u₁][l₂..u₂]`，起始位址 α，每個元素 d bytes：
- 列數 m = u₁ − l₁ + 1，行數 n = u₂ − l₂ + 1

$$\text{Row-major：} \; \text{Addr}(A[i][j]) = α + \big[(i - l_1) × n + (j - l_2)\big] × d$$

$$\text{Column-major：} \; \text{Addr}(A[i][j]) = α + \big[(j - l_2) × m + (i - l_1)\big] × d$$

> 記法：Row-major「跳過前面幾**整列**（每列 n 個）再往右走」；Column-major「跳過前面幾**整行**（每行 m 個）再往下走」。

### 2.4 下三角矩陣壓縮
n × n 下三角矩陣（i ≥ j 才存）只需 **n(n+1)/2** 個空間。
以 row-major 存入一維陣列（索引從 1 開始）：A[i][j] 的位置 = **i(i−1)/2 + j**

## 觀念 3：C 語言字串

### 3.1 字串 = 以 `'\0'` 結尾的字元陣列
```c
char s1[] = "Hello";   // 實際占 6 bytes：H e l l o \0
char s2[10] = "Hi";    // 占 10 bytes，內容 H i \0 \0 ...
```
| | `sizeof(s)` | `strlen(s)` |
|---|---|---|
| `char s1[] = "Hello";` | **6**（含 `\0`） | **5**（不含 `\0`） |
| `char s2[10] = "Hi";` | **10**（陣列大小） | **2** |
| `char *p = "Hello";` | **指標大小**（8 或 4） | 5 |

### 3.2 常用 `<string.h>` 函式
| 函式 | 功能 |
|---|---|
| `strlen(s)` | 長度（不含 `\0`） |
| `strcpy(dst, src)` | 複製（要確保 dst 夠大） |
| `strcat(dst, src)` | 串接 |
| `strcmp(a, b)` | 比較：a < b 回傳**負數**、相等回傳 **0**、a > b 回傳**正數**（依字典序 / ASCII） |

- **不能用 `==` 比較字串內容**（`==` 比較的是位址）。
- **不能用 `=` 指定字串給陣列**（`s = "abc";` 錯誤）→ 用 `strcpy`。
- 字串常值（`char *p = "abc";`）存在唯讀區，**不可修改** `p[0] = 'x';`（未定義行為）。

## 觀念 4：指標基礎

### 4.1 兩個運算子
| 運算子 | 意義 | 例子 |
|---|---|---|
| `&` | **取址**：取得變數的位址 | `&x` |
| `*` | **取值（解參考）**：取得指標所指位址的內容 | `*p` |

```c
int x = 10;
int *p = &x;     // p 存放 x 的位址；宣告中的 * 表示「p 是指標」
*p = 20;         // 透過 p 修改 x → x 變成 20
int **q = &p;    // 指標的指標
**q = 30;        // x 變成 30
```

### 4.2 記憶體方塊圖
```
  變數    位址     內容
  x      0x100    30
  p      0x200    0x100   ──▶ x
  q      0x300    0x200   ──▶ p
```
- `p` = 0x100、`*p` = 30、`&p` = 0x200
- `q` = 0x200、`*q` = 0x100、`**q` = 30

### 4.3 注意事項
- `int *p, q;` → **只有 p 是指標**，q 是 int！
- 未初始化的指標（野指標）不可解參考；不指向任何東西時設為 `NULL`。

```c

```

## 觀念 5：指標運算與陣列的關係

### 5.1 核心等式
$$a[i] \equiv *(a + i) \qquad \&a[i] \equiv a + i$$

### 5.2 指標加減
- `p + 1` 不是位址 +1，而是 **+ sizeof(所指型別)**。
  int 占 4 bytes 時，`p` = 0x1000 → `p + 1` = 0x1004。
- 兩個指向同一陣列的指標相減 = 中間相隔的**元素個數**。

### 5.3 `*p++` 系列（高頻考點）
| 運算式 | 意義（後置 `++` 優先於 `*`） |
|---|---|
| `*p++` | 取 `*p` 的值，然後 **p 往後移** |
| `(*p)++` | 取 `*p` 的值，然後**所指的內容 +1** |
| `*++p` | p 先往後移，再取值 |
| `++*p` | 所指內容先 +1，再取值 |

### 🔸 練習 5-1

p++;
printf("%d", *p + 1);

輸出為？　(A) 30 21　(B) 30 31　(C) 12 21　(D) 30 30

## 觀念 6：結構與動態記憶體配置

### 6.1 結構（struct）
```c
struct Point { int x; int y; };
struct Point pt = {3, 4};
struct Point *pp = &pt;
pt.x = 5;        // 一般變數用 .
pp->y = 10;      // 指標用 ->，等同 (*pp).y = 10
```

### 6.2 動態配置（Heap）
```c
int *arr = (int *)malloc(n * sizeof(int));   // 配置 n 個 int
if (arr == NULL) { /* 配置失敗 */ }
...
free(arr);       // 用完要釋放
arr = NULL;      // 避免懸置指標
```
| 函式 | 說明 |
|---|---|
| `malloc(size)` | 配置 size bytes，**內容未初始化** |
| `calloc(n, size)` | 配置 n × size bytes，**初始化為 0** |
| `realloc(p, size)` | 調整大小 |
| `free(p)` | 釋放 |

C++：`new` / `delete`、`new[]` / `delete[]`。Java、Python 有**垃圾回收（GC）**自動釋放。

### 6.3 常見錯誤
| 錯誤 | 說明 |
|---|---|
| **記憶體洩漏（Memory Leak）** | 配置後沒有 free，又遺失了指標 |
| **懸置指標（Dangling Pointer）** | 記憶體已 free（或區域變數已結束），指標仍指向該處 |
| 重複釋放（Double Free） | 同一塊記憶體 free 兩次 |
| 回傳區域變數的位址 | 函式結束後區域變數消失 |

```c
void reverse(char *s) {
    if (s == NULL || *s == '\0') return;
    char *end = s;
    while (*(end + 1) != '\0') end++;     /* end 指向最後一個字元 */
    while (s < end) {
        char t = *s;
        *s = *end;
        *end = t;
        s++;
        end--;
    }
}
```
評分：找到結尾（不要把 `'\0'` 換到前面）（3 分）；雙指標交換（4 分）；終止條件 `s < end`（2 分）；處理空字串（1 分）。
注意：呼叫時要傳**字元陣列**，例如 `char str[] = "Hello"; reverse(str);`，不能傳字串常值 `reverse("Hello")`（唯讀）。

void matmul(int A[2][3], int B[3][2], int C[2][2]) {
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++) {
            C[i][j] = 0;

## 📝 本章重點速記

- 部分初始化其餘補 0；`sizeof(a)/sizeof(a[0])` 算元素數；陣列傳入函式退化為指標
- 位址公式：Row-major α + [(i−l₁)·n + (j−l₂)]·d；Column-major α + [(j−l₂)·m + (i−l₁)]·d
- C / Java 列優先；Fortran / MATLAB 行優先；下三角 n(n+1)/2，A[i][j] → i(i−1)/2 + j
- `sizeof("Hello")` = 6、`strlen` = 5；strcmp 相等回傳 0；字串不能用 `==` 比內容
- `a[i] ≡ *(a+i)`；`p + 1` 移動 sizeof(型別) bytes；指標相減得元素個數
- `*p++` 移指標、`(*p)++` 改內容
- `->` 用於結構指標；malloc 未初始化、calloc 清 0；記憶體洩漏 vs 懸置指標
