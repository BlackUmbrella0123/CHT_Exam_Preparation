## 觀念 1：變數與基本資料型別

### 1.1 C 語言基本型別（常見 32/64 位元系統）
| 型別 | 大小 | 範圍 / 精度 | 格式字元 |
|---|---|---|---|
| `char` | 1 byte | −128 ~ 127 | `%c`、`%d` |
| `unsigned char` | 1 byte | 0 ~ 255 | |
| `short` | 2 bytes | −32768 ~ 32767 | `%hd` |
| `int` | **4 bytes** | 約 ±21 億（−2³¹ ~ 2³¹−1） | `%d` |
| `long long` | 8 bytes | ±9.2 × 10¹⁸ | `%lld` |
| `float` | 4 bytes | 約 **6–7 位**有效數字 | `%f` |
| `double` | 8 bytes | 約 **15–16 位**有效數字 | `%lf`（scanf）/ `%f`（printf） |

> `sizeof(char)` 在 C 標準中**保證為 1**；其他型別大小依平台而定，但考題通常採用上表。

### 1.2 識別字（變數名稱）規則
- 只能由**英文字母、數字、底線 `_`** 組成
- **不能以數字開頭**
- 不能是**保留字**（`int`、`return`、`while`…）
- **大小寫有別**（`Sum` 與 `sum` 是不同變數）

### 1.3 溢位與環繞（Wrap-around）
- **無號數**溢位會環繞：`unsigned char c = 255; c = c + 1;` → `c` 變成 **0**
- **有號數**溢位在 C 中屬於「未定義行為」，但考題常假設依 2 的補數環繞：`127 + 1 → −128`

### 1.4 常數
`const int MAX = 100;` 之後不能修改；`#define PI 3.14159` 是前置處理器的文字替換（沒有型別）。

## 觀念 2：算術運算與型別轉換

### 2.1 整數除法（最常考的陷阱）
- **整數 / 整數 = 整數**（小數部分直接捨去，C99 起**向 0 截斷**）
  - `7 / 2` → **3**；`-7 / 2` → **−3**
- **餘數 `%` 只能用在整數**，結果的**正負號跟被除數相同**
  - `7 % 3` → 1；`-7 % 3` → **−1**；`7 % -3` → **1**
- 恆等式：`(a / b) * b + a % b == a`

### 2.2 隱式型別轉換（自動提升）
運算元型別不同時，會往「範圍較大」的型別轉換：
`char/short → int → long → float → double`
```c
int a = 7, b = 2;
float c = a / b;        // 先做整數除法得 3，再轉成 3.0
float d = (float)a / b; // 7.0 / 2 → 3.5
float e = a / 2.0;      // 7 / 2.0 → 3.5
```

### 2.3 指定時的截斷
`int x = 3.99;` → x = **3**（直接捨去小數，不是四捨五入）

### 2.4 Python 的不同（補充）
| 運算 | C | Python 3 |
|---|---|---|
| `7 / 2` | 3 | **3.5**（`/` 一律為浮點除法） |
| `-7 / 2` | −3 | −3.5 |
| 整數除法 | `/` | `//`：`-7 // 2` = **−4**（向下取整） |
| `-7 % 2` | −1 | **1**（正負號跟除數相同） |

- **2-5：(B)**　由左至右：5 / 2 = 2（整數），2 × 2.0 = 4.0。

## 觀念 3：遞增 / 遞減與複合指定

| 寫法 | 意義 |
|---|---|
| `x++`（後置） | **先使用**原值，**再**加 1 |
| `++x`（前置） | **先加 1**，再使用新值 |
| `x += 3` | `x = x + 3`（`-=`、`*=`、`/=`、`%=` 同理） |

```c
int a = 5;
int b = a++;  // b = 5, a = 6
int c = ++a;  // a = 7, c = 7
```

> ⚠️ `i = i++;`、`a[i] = i++;`、`printf("%d %d", i++, i++);` 這類在**同一敘述中多次修改同一變數**的寫法，在 C 中是**未定義行為**，不同編譯器結果不同，正式程式不要這樣寫。（若考題出現，通常選項會有「無法確定 / 依編譯器而定」）

### 🔸 練習 3-2

(A) 7　(B) 10　(C) 14　(D) 30

輸出為？　(A) 3 2 4　(B) 3 2 6　(C) 2 2 4　(D) 3 3 6

<details>
<summary>▶ 解答</summary>

- **3-2：(C)**
- **3-3：(C)**　x = 7；接著 x = 7 × (7 − 5) = 14。複合指定的右邊會**整個**先算完（不是 `x * x − 5` = 44）。

</details>

## 觀念 4：關係運算、邏輯運算與短路求值

### 4.1 真假值
- C 語言中，**0 為假，非 0 皆為真**；比較運算的結果是 **1（真）或 0（假）**。
- `=` 是**指定**，`==` 才是**比較**：`if (x = 0)` 會把 x 設成 0，條件恆為假！

### 4.2 短路求值（Short-circuit）
- `A && B`：若 **A 為假**，B **不會執行**
- `A || B`：若 **A 為真**，B **不會執行**

```c
int a = 0, b = 5;
if (a != 0 && b / a > 1) { ... }  // 安全：a 為 0 時不會執行 b / a
```

### 4.3 連續比較的陷阱
`5 > 3 > 1` 在 C 中是 `(5 > 3) > 1` → `1 > 1` → **0**（假）
（Python 則支援數學式的連鎖比較，`5 > 3 > 1` 為 True）

### 🔸 練習 4-1
```c
int i = 1, j = 1;
if (i++ > 1 && j++ > 0) { }
printf("%d %d", i, j);
```
輸出為？　(A) 1 1　(B) 2 1　(C) 2 2　(D) 1 2

### 🔸 練習 4-2
```c
int x = 0, y = 0;
if (++x || ++y) { }
printf("%d %d", x, y);
```
輸出為？　(A) 0 0　(B) 1 0　(C) 1 1　(D) 0 1

### 🔸 練習 4-3
```c
int a = 3;
if (a = 0) printf("A");
else       printf("B");
printf("%d", a);
```
輸出為？　(A) A3　(B) B3　(C) A0　(D) B0

### 🔸 練習 4-4
C 語言中，`printf("%d", 10 > 5 > 2);` 的輸出為？
(A) 1　(B) 0　(C) 2　(D) 編譯錯誤

### 🔸 練習 4-5
```c

int r = !a + !b + (a && b) + (a || b);
printf("%d", r);
```
輸出為？　(A) 1　(B) 2　(C) 3　(D) 4

<details>
<summary>▶ 解答</summary>

- **4-1：(B)**　`i++ > 1` 用 1 比較 → 假（i 變 2），短路，`j++` 不執行。
- **4-2：(B)**　`++x` 為 1（真），短路，`++y` 不執行。
- **4-3：(D)**　`a = 0` 指定後值為 0 → 假 → 印 B；a 已變 0。
- **4-4：(B)**　(10 > 5) = 1；1 > 2 = 0。
- **4-5：(B)**　!5 = 0；!0 = 1；5 && 0 = 0；5 || 0 = 1 → 0 + 1 + 0 + 1 = 2。
</details>

## 觀念 5：位元運算

| 運算子 | 名稱 | 範例（a = 12 = 1100₂，b = 10 = 1010₂） |
|---|---|---|
| `&` | AND | `a & b` = 1000₂ = **8** |
| `\|` | OR | `a \| b` = 1110₂ = **14** |
| `^` | XOR | `a ^ b` = 0110₂ = **6** |
| `~` | NOT（取補數） | `~a` = **−13**（2 的補數：`~x = −x − 1`） |
| `<<` | 左移 | `a << 2` = 110000₂ = **48**（× 4） |
| `>>` | 右移 | `a >> 2` = 11₂ = **3**（÷ 4） |

### 常見技巧
| 技巧 | 寫法 |
|---|---|
| 判斷奇偶 | `n & 1`（1 為奇數） |
| 乘以 2ᵏ / 除以 2ᵏ | `n << k` / `n >> k` |
| 判斷是否為 2 的次方 | `n > 0 && (n & (n - 1)) == 0` |
| 交換兩數（不用暫存變數） | `a ^= b; b ^= a; a ^= b;` |
| 設定第 k 位為 1 | `n \| (1 << k)` |
| 清除第 k 位 | `n & ~(1 << k)` |
| 計算 1 的個數 | 重複 `n &= (n - 1)` 直到 0 |

(A) 2　(B) 6　(C) 8　(D) 14

### 🔸 練習 5-2

(A) 7　(B) 16　(C) 19　(D) 48

- **5-2：(B)**　~x = −x − 1 = −6。
- **5-3：(B)**　XOR 交換。
- **5-4：(B)**　29 = 11101₂，有 4 個 1。

</details>

## 觀念 6：運算子優先順序與三元運算子

### 6.1 優先順序（由高到低，常考的部分）
| 等級 | 運算子 | 結合性 |
|---|---|---|
| 1 | `()` `[]` `->` `.` 後置`++ --` | 左→右 |
| 2 | 前置`++ --` `!` `~` 正負號 `*`(取值) `&`(取址) `(型別)` `sizeof` | **右→左** |
| 3 | `*` `/` `%` | 左→右 |
| 4 | `+` `-` | 左→右 |
| 5 | `<<` `>>` | 左→右 |
| 6 | `<` `<=` `>` `>=` | 左→右 |
| 7 | `==` `!=` | 左→右 |
| 8 | `&` | 左→右 |
| 9 | `^` | 左→右 |
| 10 | `\|` | 左→右 |
| 11 | `&&` | 左→右 |
| 12 | `\|\|` | 左→右 |
| 13 | `? :` | **右→左** |
| 14 | `=` `+=` `-=` … | **右→左** |
| 15 | `,` | 左→右 |

> 口訣：**「單目 > 算術 > 位移 > 關係 > 位元 > 邏輯 > 三元 > 指定 > 逗號」**
> 最常見陷阱：**位元運算 `&` `|` 的優先順序比 `==` 低**，所以 `x & 1 == 0` 會被解讀成 `x & (1 == 0)`！

### 6.2 三元運算子
`條件 ? 值1 : 值2` → 條件為真取值1，否則取值2。

### 🔸 練習 6-1

(A) 0　(B) 4　(C) 9　(D) 14

### 🔸 練習 6-2

(A) 5　(B) 6　(C) 4　(D) 3

### 🔸 練習 6-3

```c
else            printf("odd");
```
輸出為？　(A) even　(B) odd　(C) 編譯錯誤　(D) 不輸出

### 🔸 練習 6-4
```c

```
輸出為？　(A) 10　(B) 20　(C) 100　(D) 200

### 🔸 練習 6-5
```c

a = (b = 3, b + 2);
printf("%d %d", a, b);
```
輸出為？　(A) 3 3　(B) 5 3　(C) 5 5　(D) 3 5

<details>
<summary>▶ 解答</summary>

- **6-1：(B)**　`3 * 4` = 12 → `12 % 5` = 2 → 2 + 2 = 4。
- **6-2：(B)**　`+` 優先於 `<<`：(1 + 2) << 1 = 6。
- **6-3：(B)**　`1 == 0` 為 0 → `4 & 0` = 0 → 假 → 印 odd（即使 4 是偶數！）。應寫成 `(x & 1) == 0`。
- **6-4：(C)**　三元右結合：`a > b ? a : (b > 15 ? 100 : 200)`；10 > 20 為假 → 20 > 15 為真 → 100。
- **6-5：(B)**　逗號運算子取最右邊的值：b = 3，a = 3 + 2 = 5。
</details>

## 觀念 7：格式化輸出 printf

| 格式 | 意義 | 範例 | 輸出 |
|---|---|---|---|
| `%d` | 十進位整數 | `printf("%d", 'A')` | `65` |
| `%c` | 字元 | `printf("%c", 66)` | `B` |
| `%f` | 浮點數（預設 **6 位小數**） | `printf("%f", 3.5)` | `3.500000` |
| `%.2f` | 小數 2 位（四捨五入） | `printf("%.2f", 3.14159)` | `3.14` |
| `%5d` | 寬度 5，**靠右** | `printf("[%5d]", 42)` | `[   42]` |
| `%-5d` | 寬度 5，**靠左** | `printf("[%-5d]", 42)` | `[42   ]` |
| `%05d` | 寬度 5，前面補 0 | `printf("%05d", 42)` | `00042` |
| `%x` / `%X` | 十六進位 | `printf("%x", 255)` | `ff` |
| `%o` | 八進位 | `printf("%o", 8)` | `10` |
| `%e` | 科學記號 | `printf("%e", 1234.5)` | `1.234500e+03` |
| `%s` | 字串 | | |
| `%%` | 印出 % | | `%` |

> `printf` 的回傳值是**印出的字元數**。

```c
int isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}

int countOnes(unsigned int n) {
    int count = 0;
    while (n) {
        n &= (n - 1);   /* 每次消去最低位的 1 */
        count++;
    }
    return count;
}
```
- `n & (n − 1)` 會把 n **最低位的 1 清成 0**。2 的次方只有一個 1，清掉後必為 0。（3 分）
- (1) 要處理 n ≤ 0（2 分），並注意 `==` 優先順序高於 `&`，**必須加括號**（1 分）。
- (2) 迴圈正確（4 分）。也可用 `count += n & 1; n >>= 1;` 的寫法。
