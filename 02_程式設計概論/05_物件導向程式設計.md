## 觀念 1：類別、物件與封裝

### 1.1 基本名詞
- **類別（Class）**：藍圖，定義屬性（欄位）與行為（方法）
- **物件（Object）/ 實例（Instance）**：依類別建立出的實體，`new` 出來的東西
- **OOP 三大特性：封裝（Encapsulation）、繼承（Inheritance）、多型（Polymorphism）**（有時再加上「抽象」成為四大特性）

### 1.2 封裝與存取修飾子（Java）
| 修飾子 | 同類別 | 同套件 | 子類別（不同套件） | 任何地方 |
|---|---|---|---|---|
| `private` | ✅ | ❌ | ❌ | ❌ |
| （預設 / package-private） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

> 封裝的做法：欄位設為 `private`，提供 `public` 的 getter / setter，在 setter 中檢查資料合理性。
> C++ 類別成員預設為 **private**；`struct` 成員預設為 **public**。

```java
public class Account {
    private int balance;                     // 外部無法直接存取
    public int getBalance() { return balance; }
    public void deposit(int amt) {
        if (amt > 0) balance += amt;         // 透過方法控管
    }
}
```

## 觀念 2：建構子、this 與 static

### 2.1 建構子（Constructor）
- **名稱與類別相同，沒有回傳型別**（連 void 都不寫）
- `new` 物件時自動呼叫，用來初始化
- 若**完全沒寫**任何建構子，編譯器會提供**無參數的預設建構子**；**只要寫了任何一個**，就不再自動提供
- 可多載（多個不同參數的建構子）；`this(...)` 呼叫同類別其他建構子（必須是第一行）
- C++ 另有**解構子** `~ClassName()`，物件消滅時呼叫；Java 依賴垃圾回收

### 2.2 this
指向「目前這個物件」，常用於區分同名的欄位與參數：`this.name = name;`

### 2.3 static（類別成員）
- **static 欄位**：屬於類別，**所有物件共用一份**
- **static 方法**：可用 `類別名.方法()` 呼叫；**不能直接使用 this 或非 static 成員**

```java
class Car {
    static int count = 0;   // 所有 Car 共用
    int id;
    Car() { count++; id = count; }
}
```

## 觀念 3：繼承

### 3.1 基本
```java
class Animal { ... }
class Dog extends Animal { ... }   // Dog「是一種」Animal（is-a）
```
- 子類別繼承父類別的非 private 成員，可**新增**與**覆寫**
- **Java 類別只能單一繼承**（一個 extends），但可**實作多個介面**
- **C++ 支援多重繼承**，可能產生**菱形繼承（Diamond Problem）**，用 `virtual` 繼承解決
- 所有 Java 類別最終都繼承自 `Object`

### 3.2 建構子呼叫順序
**先父後子**：建立子類別物件時，會先執行父類別建構子（子類別建構子第一行隱含 `super()`）。
（C++ 解構子則是**先子後父**）

### 3.3 is-a vs has-a
- **is-a**：繼承（狗是動物）
- **has-a**：組合 / 聚合，一個類別擁有另一個類別的物件當欄位（車有引擎）
- 設計原則：**優先使用組合而非繼承**

## 觀念 4：多載（Overloading） vs 覆寫（Overriding）

| | **多載 Overloading** | **覆寫 Overriding** |
|---|---|---|
| 發生位置 | **同一類別**（或繼承中） | **子類別**改寫父類別方法 |
| 方法名稱 | 相同 | 相同 |
| 參數 | **必須不同**（個數、型別或順序） | **必須相同** |
| 回傳型別 | 可不同，但**只有回傳型別不同不算多載** | 相同（或其子型別） |
| 存取權限 | 無限制 | **不能比父類別更嚴格** |
| 決定時機 | **編譯時期**（靜態繫結） | **執行時期**（動態繫結） |
| 屬於 | 編譯時多型 | **執行時多型** |

> `final` 方法不能被覆寫；`final` 類別不能被繼承；`static` 方法不會被覆寫（只會被「隱藏」）。

## 觀念 5：多型與動態繫結（必考）

### 5.1 父類別參考指向子類別物件
```java
class Animal { void speak() { System.out.print("..."); } }
class Dog extends Animal { void speak() { System.out.print("Woof"); } }
class Cat extends Animal { void speak() { System.out.print("Meow"); } }

Animal a = new Dog();   // 向上轉型（Upcasting），自動
a.speak();              // 印 Woof ← 依「實際物件」決定
```

### 5.2 判斷規則（Java）
| 呼叫的東西 | 依據 |
|---|---|
| **一般（instance）方法** | **實際物件型別**（動態繫結） |
| **欄位（field）** | **參考變數的宣告型別**（不具多型） |
| **static 方法** | **參考變數的宣告型別**（不具多型） |
| 能不能呼叫某方法（編譯檢查） | **參考變數的宣告型別**裡必須有這個方法 |

### 5.3 C++ 的差異
C++ 中**必須將父類別方法宣告為 `virtual`** 才會動態繫結；否則依指標型別呼叫父類別版本。
**純虛擬函式** `virtual void f() = 0;` → 該類別成為抽象類別。

## 觀念 6：抽象類別與介面

| | **抽象類別 abstract class** | **介面 interface** |
|---|---|---|
| 能否 `new` | ❌ | ❌ |
| 方法 | 可有抽象方法與一般方法 | 預設為 `public abstract`；Java 8 起可有 `default`、`static` 方法 |
| 欄位 | 一般欄位皆可 | 只能是 `public static final` 常數 |
| 建構子 | **可以有** | **沒有** |
| 繼承數量 | 只能 `extends` 一個 | 可 `implements` 多個 |
| 語意 | is-a，共同的基礎 | can-do，能力 / 規範 |

- 有抽象方法的類別**必須**宣告為 abstract；但 abstract 類別**不一定**要有抽象方法。
- 子類別若未實作所有抽象方法，自己也必須是 abstract。

## 觀念 7：例外處理

```java
try {
    // 可能出錯的程式
} catch (ArithmeticException e) {
    // 處理特定例外
} catch (Exception e) {
    // 處理其他例外（較廣的要放後面）
} finally {
    // 無論是否發生例外都會執行（常用來釋放資源）
}
```
- 發生例外後，`try` 區塊**剩下的程式不會執行**，直接跳到對應的 catch。
- `finally` **一定會執行**（即使 try 或 catch 中有 `return`）。
- **Checked Exception**（如 `IOException`）必須處理或宣告 `throws`；**Unchecked**（`RuntimeException` 子類，如 `NullPointerException`、`ArrayIndexOutOfBoundsException`、`ArithmeticException`）可不處理。
- catch 順序：**子類別例外要放在父類別例外之前**，否則編譯錯誤。

    abstract double area();
}

class Circle extends Shape {
    private double r;

        BankAccount a = new BankAccount(100);
        try {
            a.withdraw(500);
        } catch (IllegalStateException e) {
            System.out.println("錯誤：" + e.getMessage());
        } finally {
            System.out.println("餘額：" + a.getBalance());
        }
        System.out.println("帳戶數：" + BankAccount.getCount());
    }
}

## 📝 本章重點速記

- 三大特性：封裝、繼承、多型；private < 預設 < protected < public
- 建構子無回傳型別；寫了任何建構子就沒有預設建構子；static 成員全體共用
- 建構子**先父後子**；Java 類別單一繼承、介面可多個；C++ 可多重繼承（菱形問題）
- 多載：參數不同、編譯時期；覆寫：簽章相同、執行時期、權限不能更嚴格
- **方法看實際物件，欄位與 static 看宣告型別**；能否呼叫看宣告型別
- C++ 要 `virtual` 才有動態繫結
- 抽象類別可有建構子、不能 new；介面欄位為 public static final
- finally 一定執行；子類例外的 catch 放前面
