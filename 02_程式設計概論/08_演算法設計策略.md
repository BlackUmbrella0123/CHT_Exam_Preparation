## 觀念 1：分治法（Divide and Conquer）

### 1.1 三步驟
1. **分割（Divide）**：把問題切成數個**互相獨立**的較小子問題
2. **征服（Conquer）**：遞迴解決子問題
3. **合併（Combine）**：把子問題的解合併成原問題的解

### 1.2 代表演算法
| 演算法 | 遞迴式 | 複雜度 |
|---|---|---|
| **二元搜尋** | T(n) = T(n/2) + 1 | O(log n) |
| **合併排序** | T(n) = 2T(n/2) + n | O(n log n) |
| **快速排序** | 平均 2T(n/2) + n | 平均 O(n log n) |
| 找最大最小值 | | 約 3n/2 次比較 |
| **Strassen 矩陣乘法** | T(n) = 7T(n/2) + n² | O(n^2.81)（一般為 O(n³)） |
| Karatsuba 大數乘法 | T(n) = 3T(n/2) + n | O(n^1.58) |

> 分治 vs 動態規劃：**分治的子問題互相獨立**；**DP 的子問題會重疊**（重複計算）。

## 觀念 2：貪婪法（Greedy）

### 2.1 核心精神
每一步都做**當下看起來最好**的選擇，且**不回頭修改**。
- 優點：簡單、快速
- 缺點：**不保證得到全域最佳解**，必須證明該問題具有「貪婪選擇性質」

### 2.2 代表演算法（貪婪可得最佳解）
| 問題 | 貪婪策略 |
|---|---|
| **活動選擇** | 每次選**最早結束**且不衝突的活動 |
| **霍夫曼編碼** | 每次合併**頻率最小的兩個** |
| **Kruskal** 最小生成樹 | 每次選**權重最小**且不形成迴路的邊 |
| **Prim** 最小生成樹 | 每次從已選集合往外選**最小權重**的邊 |
| **Dijkstra** 最短路徑 | 每次確定**目前距離最小**的頂點 |
| **分數背包**（可切割） | 依**價值/重量比**由高到低裝 |

### 2.3 貪婪失敗的例子
- **0/1 背包**（物品不可切割）→ 需用 DP
- **找零錢**：硬幣 {1, 5, 10, 50} 可以；但 {1, 3, 4} 找 6 元，貪婪 4+1+1（3 枚），最佳 3+3（2 枚）

### 2.4 霍夫曼編碼
1. 每個字元當成一棵樹，權重 = 頻率
2. 每次取出**最小的兩棵**合併，新樹權重為兩者之和
3. 重複直到剩一棵；左邊標 0、右邊標 1
- 頻率越高 → 碼越短；是**前綴碼**（沒有任何碼是另一個碼的前綴）
- **總位元數 = Σ（頻率 × 碼長）**

## 觀念 3：動態規劃（Dynamic Programming）

### 3.1 適用條件
1. **最佳子結構**：最佳解由子問題的最佳解組成
2. **重疊子問題**：相同子問題會被重複計算 → **把答案記錄下來**（用空間換時間）

### 3.2 兩種實作方式
- **由上而下 + 記憶化（Memoization）**：遞迴，算過的存起來
- **由下而上 + 建表（Tabulation）**：從最小子問題開始填表

### 3.3 代表問題
| 問題 | 遞迴關係 |
|---|---|
| 費氏數列 | F(n) = F(n−1) + F(n−2) |
| 爬樓梯（一次 1 或 2 階） | W(n) = W(n−1) + W(n−2) |
| **0/1 背包** | dp[i][w] = max(dp[i−1][w], dp[i−1][w − wᵢ] + vᵢ) |
| **最長共同子序列 LCS** | 字元相同：dp[i−1][j−1] + 1；否則 max(dp[i−1][j], dp[i][j−1]) |
| 找零錢方法數 | ways[x] += ways[x − coin]（對每種硬幣） |
| 矩陣鏈乘 | 找最少乘法次數的括號方式 |
| **Floyd-Warshall** | 所有點對最短路徑 |
| 編輯距離 | 插入 / 刪除 / 替換的最少次數 |

## 觀念 4：回溯法與分支限界

### 4.1 回溯法（Backtracking）
在**狀態空間樹**上做 **DFS**，一旦發現目前的部分解**不可能**成為答案，就**剪枝（Pruning）**並退回上一步。
- 代表問題：**N 皇后**、子集合總和、排列組合、數獨、圖形著色、迷宮
- 4 皇后有 **2** 組解；8 皇后有 **92** 組解

### 4.2 分支限界（Branch and Bound）
用於**最佳化問題**；常以 **BFS 或最佳優先**搜尋，計算每個節點的**界限值（bound）**，若不可能優於目前最佳解就剪掉。
- 代表問題：**旅行推銷員問題（TSP）**、0/1 背包、工作指派

### 4.3 排列產生（回溯範例）
```c
void perm(char s[], int k, int n) {
    if (k == n) { printf("%s ", s); return; }
    for (int i = k; i < n; i++) {
        swap(&s[k], &s[i]);
        perm(s, k + 1, n);
        swap(&s[k], &s[i]);   // 回溯：還原
    }
}
```

## 觀念 5：圖形演算法——最短路徑與最小生成樹

### 5.1 最短路徑
| 演算法 | 類型 | 策略 | 負權重 | 複雜度 |
|---|---|---|---|---|
| **Dijkstra** | 單一起點 | **貪婪** | ❌ 不可 | O(V²)；用堆積 O((V+E) log V) |
| **Bellman-Ford** | 單一起點 | DP | ✅ 可，且可**偵測負迴路** | O(VE) |
| **Floyd-Warshall** | **所有點對** | **DP** | ✅ 可（不可有負迴路） | **O(V³)** |
| BFS | 單一起點 | — | **無權重圖** | O(V+E) |

### 5.2 最小生成樹（MST）
- 生成樹：連通所有頂點、無迴路，**恰有 V − 1 條邊**
- MST：總權重最小的生成樹

| 演算法 | 作法 | 適合 | 複雜度 |
|---|---|---|---|
| **Kruskal** | 邊由小到大排序，依序加入**不形成迴路**的邊（用 Union-Find 判斷） | **稀疏圖** | O(E log E) |
| **Prim** | 從一個頂點出發，每次加入連接「樹內」與「樹外」的**最小邊** | **稠密圖** | O(V²) 或 O(E log V) |
| Sollin（Borůvka） | 每個元件同時選最小外連邊 | | |

### 範例圖（無向加權）
| 邊 | A-B | A-C | B-C | B-D | C-D | D-E |
|---|---|---|---|---|---|---|
| 權重 | 4 | 1 | 2 | 1 | 5 | 3 |

```
      4
  A ───── B
  │     ╱ │
 1│   2╱  │1
  │  ╱    │

      5       3
```

| 步驟 | 確定頂點 | A | B | C | D | E |

| 1 | A | **0** | 4 | 1 | ∞ | ∞ |
| 2 | C | | 3（1+2） | **1** | 6（1+5） | ∞ |
| 3 | B | | **3** | | 4（3+1） | ∞ |

## 觀念 6：計算複雜度類別（P / NP）

| 類別 | 定義 |
|---|---|
| **P** | 可以在**多項式時間內解出**的問題（如排序、最短路徑、MST） |
| **NP** | 給定一個解，可以在**多項式時間內驗證**的問題（P ⊆ NP） |
| **NP-Complete** | 屬於 NP，且所有 NP 問題都能在多項式時間**歸約**到它（NP 中最難的） |
| **NP-Hard** | 至少和 NP-Complete 一樣難，但**不一定屬於 NP** |

- **第一個被證明的 NP-Complete 問題：SAT（布林可滿足性問題）**（Cook-Levin 定理）
- 常見 NP-Complete：**3-SAT、旅行推銷員（決策版）、漢米爾頓迴路、0/1 背包（決策版）、圖形著色、頂點覆蓋、子集合總和、團（Clique）**
- 對照：**尤拉路徑 / 迴路**（每條**邊**恰走一次）屬於 **P**；**漢米爾頓迴路**（每個**頂點**恰走一次）是 **NP-Complete**
- 若**任何一個** NP-Complete 問題能在多項式時間解出 → **P = NP**（目前仍未解決）
- **停機問題（Halting Problem）**：**不可判定**（不存在任何演算法能解）

## 📝 本章重點速記

| 策略 | 精神 | 代表 |
|---|---|---|
| **分治** | 切成獨立子問題 → 合併 | 合併排序、快速排序、二元搜尋、Strassen |
| **貪婪** | 每步取當下最佳，不回頭 | Dijkstra、Prim、Kruskal、霍夫曼、活動選擇、分數背包 |
| **動態規劃** | 子問題重疊，記錄答案 | 0/1 背包、LCS、Floyd-Warshall、Bellman-Ford、矩陣鏈乘、費氏 |
| **回溯** | DFS + 剪枝 | N 皇后、子集合、排列、數獨 |
| **分支限界** | 界限值剪枝（最佳化） | TSP、0/1 背包 |

- 找零 {1,3,4} 湊 6 → 貪婪失敗；0/1 背包要用 DP
- 霍夫曼：每次合併最小兩個；總位元 = Σ 頻率 × 碼長
- Dijkstra 不能負權重；Bellman-Ford 可偵測負迴路；Floyd O(V³) 所有點對
- MST 有 V − 1 條邊；Kruskal 選最小邊（稀疏圖），Prim 從點長出去（稠密圖）
- SAT 第一個 NPC；尤拉迴路 P、漢米爾頓迴路 NPC；停機問題不可判定
