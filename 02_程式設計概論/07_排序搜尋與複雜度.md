## 觀念 1：時間複雜度與 Big-O

### 1.1 漸近符號
| 符號 | 意義 | 類比 |
|---|---|---|
| **O（Big-O）** | 上界（最多這麼慢） | ≤ |
| **Ω（Big-Omega）** | 下界（至少這麼慢） | ≥ |
| **Θ（Big-Theta）** | 緊密界（上下界相同） | = |

### 1.2 化簡規則
- **去掉常數係數**：5n² → O(n²)
- **只留最高次項**：3n² + 100n log n + 5 → O(n²)
- 對數底數不重要：log₂n、log₁₀n 都是 O(log n)

### 1.3 成長速度排序（必背）
$$O(1) < O(\log n) < O(\sqrt{n}) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

### 1.4 迴圈分析
| 程式結構 | 複雜度 |
|---|---|
| `for (i = 0; i < n; i++)` | O(n) |
| `for (i = 1; i < n; i *= 2)` 或 `i /= 2` | **O(log n)** |
| 兩層 `for` 各到 n | O(n²) |
| `for (i...n) for (j = i; j < n; j++)` | O(n²)（n(n+1)/2） |
| `for (i...n) for (j = 1; j < n; j *= 2)` | **O(n log n)** |
| `for (i = 1; i * i <= n; i++)` | O(√n) |
| 兩段**不巢狀**的 O(n) 迴圈 | O(n)（相加） |

## 觀念 2：遞迴關係式

### 2.1 常見遞迴式（直接背）
| 遞迴式 | 解 | 代表演算法 |
|---|---|---|
| T(n) = T(n−1) + 1 | **O(n)** | 線性遞迴、階乘 |
| T(n) = T(n/2) + 1 | **O(log n)** | **二元搜尋** |
| T(n) = T(n−1) + n | **O(n²)** | 選擇 / 插入排序的遞迴版、快速排序最差 |
| T(n) = 2T(n/2) + 1 | **O(n)** | 二元樹走訪 |
| T(n) = 2T(n/2) + n | **O(n log n)** | **合併排序、快速排序平均** |
| T(n) = 2T(n−1) + 1 | **O(2ⁿ)** | **河內塔** |
| T(n) = T(n−1) + T(n−2) + 1 | **O(2ⁿ)**（約 1.618ⁿ） | 遞迴費氏數列 |

### 2.2 主定理（Master Theorem）簡易版
$T(n) = a\,T(n/b) + O(n^d)$，比較 **d** 與 **log_b a**：
| 情況 | 結果 |
|---|---|
| d > log_b a | **O(nᵈ)** |
| d = log_b a | **O(nᵈ log n)** |
| d < log_b a | **O(n^{log_b a})** |

例：T(n) = 2T(n/2) + n → a=2, b=2, d=1，log₂2 = 1 = d → O(n log n) ✓

## 觀念 3：搜尋

### 3.1 循序搜尋（Sequential / Linear Search）
- 不需排序；逐一比對
- 時間 **O(n)**；平均比較 (n+1)/2 次

### 3.2 二元搜尋（Binary Search）
- **前提：資料必須已排序**，且能隨機存取（陣列，不適合鏈結串列）
- 時間 **O(log n)**；**最多比較 ⌊log₂n⌋ + 1 次**

```c
int binarySearch(int a[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (a[mid] == key) return mid;
        else if (a[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```
> 實務上寫 `mid = low + (high - low) / 2` 可避免 low + high 溢位。

### 3.3 其他
- **內插搜尋**：依數值比例估計位置，資料均勻分布時平均 O(log log n)
- **雜湊搜尋**：平均 O(1)

## 觀念 4：基本排序（O(n²)）

### 4.1 氣泡排序（Bubble Sort）
相鄰兩兩比較，大的往後換。**每一輪結束，最大值會「浮」到最後面**。
加上「本輪沒有交換就提早結束」，最佳情況（已排序）為 **O(n)**。

`[5, 1, 4, 2, 8]` 第 1 輪：
```
(5,1)換→[1,5,4,2,8] (5,4)換→[1,4,5,2,8] (5,2)換→[1,4,2,5,8] (5,8)不換
第 1 輪結果：[1, 4, 2, 5, 8]
```

### 4.2 選擇排序（Selection Sort）
每一輪從未排序部分**選出最小值**，與該輪第一個位置交換。
**比較次數固定 n(n−1)/2**，最佳最差都是 O(n²)；**交換次數最多 n − 1 次**（交換次數最少的排序）；**不穩定**。

`[64, 25, 12, 22, 11]`
```
第 1 輪：最小 11 與 64 交換 → [11, 25, 12, 22, 64]
第 2 輪：最小 12 與 25 交換 → [11, 12, 25, 22, 64]
```

### 4.3 插入排序（Insertion Sort）
像整理撲克牌：把第 i 個元素**插入**前面已排序的部分。
**資料幾乎已排序時非常快**，最佳 **O(n)**；穩定。

`[5, 2, 4, 6, 1, 3]`
```
i=1：插入 2 → [2, 5, 4, 6, 1, 3]
i=2：插入 4 → [2, 4, 5, 6, 1, 3]
i=3：插入 6 → [2, 4, 5, 6, 1, 3]
i=4：插入 1 → [1, 2, 4, 5, 6, 3]
```

## 觀念 5：高效排序（O(n log n)）

### 5.1 合併排序（Merge Sort）
**分治法**：一直對半切到只剩 1 個，再兩兩**合併**成有序序列。
- 時間：**最佳 / 平均 / 最差皆 O(n log n)**
- 空間：**O(n)**（需要輔助陣列）
- **穩定**；適合**外部排序**與鏈結串列

### 5.2 快速排序（Quick Sort）
**分治法**：選一個**基準值（pivot）**，分割成「比 pivot 小」和「比 pivot 大」兩部分，再遞迴排序。
- 平均 **O(n log n)**，實務上通常最快
- **最差 O(n²)**：每次 pivot 都是最大或最小值（例：**資料已排序**且選第一個元素當 pivot）
- 改善：隨機選 pivot、**三數取中（median-of-three）**
- 空間：O(log n)（遞迴堆疊）；**不穩定**

### 5.3 堆積排序（Heap Sort）
建立最大堆積 O(n) → 反覆將根（最大值）與最後一個交換、縮小堆積並向下調整。
- **最佳 / 平均 / 最差皆 O(n log n)**，空間 **O(1)**；**不穩定**

### 5.4 謝爾排序（Shell Sort）
插入排序的改良，先以較大間隔（gap）排序再逐步縮小；**不穩定**；複雜度依 gap 序列而定（約 O(n^1.3~1.5)）。

## 觀念 6：非比較排序與總比較表

### 6.1 比較式排序的下界
任何**以比較為基礎**的排序，最差情況至少需要 **Ω(n log n)** 次比較（決策樹高度）。

### 6.2 非比較式排序（可突破 n log n）
| 排序 | 原理 | 時間 | 條件 |
|---|---|---|---|
| **計數排序 Counting** | 統計每個值出現次數 | O(n + k) | 值的範圍 k 不大 |
| **基數排序 Radix（LSD）** | 從**最低位**到最高位，每位用穩定排序 | O(d × (n + k)) | d 為位數 |
| 桶子排序 Bucket | 分到多個桶子各自排序 | 平均 O(n + k) | 資料均勻分布 |

基數排序範例 `[170, 45, 75, 90, 802, 24, 2, 66]`，依**個位數**排序（穩定）後：
`[170, 90, 802, 2, 24, 45, 75, 66]`

### 6.3 🔥 排序總比較表（必背）
| 排序 | 最佳 | 平均 | 最差 | 額外空間 | 穩定 |
|---|---|---|---|---|---|
| 氣泡 Bubble | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 選擇 Selection | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| 插入 Insertion | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 謝爾 Shell | O(n log n) | ~O(n^1.3) | O(n²) | O(1) | ❌ |
| **合併 Merge** | O(n log n) | O(n log n) | **O(n log n)** | **O(n)** | ✅ |
| **快速 Quick** | O(n log n) | O(n log n) | **O(n²)** | O(log n) | ❌ |
| **堆積 Heap** | O(n log n) | O(n log n) | O(n log n) | **O(1)** | ❌ |
| 計數 Counting | O(n+k) | O(n+k) | O(n+k) | O(k) | ✅ |
| 基數 Radix | O(d(n+k)) | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✅ |

> **穩定排序口訣：「插泡合基（計數）」穩定；「選快堆謝」不穩定。**
> **穩定**：相同鍵值的資料，排序後仍保持原本的相對順序。

```c
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];     /* 往後移 */
            j--;
        }
        a[j + 1] = key;
    }
}
```

**(3)**（2 分）最佳 **O(n)**：資料已排序（內層 while 不執行）；最差 **O(n²)**：資料完全逆序。

**(1)**（5 分）
```c
void swap(int *x, int *y) { int t = *x; *x = *y; *y = t; }

int partition(int a[], int lo, int hi) {
    int pivot = a[hi], i = lo - 1;
    for (int j = lo; j < hi; j++) {
        if (a[j] <= pivot) {
            i++;
            swap(&a[i], &a[j]);
        }
    }
    swap(&a[i + 1], &a[hi]);
    return i + 1;
}

void quickSort(int a[], int lo, int hi) {
    if (lo < hi) {
        int p = partition(a, lo, hi);
        quickSort(a, lo, p - 1);
        quickSort(a, p + 1, hi);
    }
}
```

## 📝 本章重點速記

- 成長速度：1 < log n < √n < n < n log n < n² < n³ < 2ⁿ < n!
- `i *= 2` / `i /= 2` → log n；巢狀相乘、並列相加
- T(n)=T(n/2)+1 → log n；2T(n/2)+n → n log n；T(n−1)+n → n²；2T(n−1)+1 → 2ⁿ
- 主定理：比較 d 與 log_b a
- 二元搜尋需排序、最多 ⌊log₂n⌋+1 次比較
- 氣泡：每輪最大值到最後；選擇：比較固定 n(n−1)/2、交換最少；插入：近乎排序時最快
- 快速排序最差 O(n²)（已排序 + 首元素 pivot）；合併 O(n) 空間、穩定、外部排序；堆積 O(1) 空間
- 穩定：插泡合基（計數）；不穩定：選快堆謝
- 比較排序下界 Ω(n log n)
